# 文庫動畫候選項（待互動與資訊設計確認）

更新：2026-10-10。

目前只記錄改進方向，暫不實作，也不視為已確認的開發清單。先確定文庫的操作流程、各區域顯示哪些資訊，以及哪些狀態值得提示，再依實際需求選擇動畫；觸發方式、時長與優先順序屆時決定。

Enter、拖曳誤觸、鍵盤作用範圍及詳情退場銜接已完成修正，現行契約與驗證見 [AGENTS.md 第 13 節](../AGENTS.md#13-文庫頁與-ai-解讀2026-10-09)。以下候選項不包含這些已完成工作。

## 候選方向

| 場景 | 可考慮的動畫 | 實作前需確認 |
| --- | --- | --- |
| 切換文獻／月份 | 標題、編號按導航方向連續滾動；快速切換時接續至最新目標 | 標題與編號保留哪些欄位；方向键、搜尋跳轉是否使用不同回應 |
| 開啟詳情 | 短版多階段封面解密、按文字實際行數揭開遮罩 | 詳情最終資訊層級；封面與正文載入先後；是否允許立即閱讀或跳過演出，避免用動畫製造等待 |
| 詳情分頁 | 共用滑動指示線、內容短暫淡入 | 分頁內容與排序；是否保留捲動位置；切頁和背景資料更新應如何區別 |
| 閱讀後返回文庫 | 恢復場景位置，縮短或略過首次入場演出 | 返回時恢復選中項、鏡頭還是詳情；切到其他頁再返回是否採同一規則 |
| 文獻與任務更新 | 新文獻局部進場；翻譯／AI 解讀完成時局部提示一次 | 哪些事件需要提示、提示放在哪裡；批次完成、失敗與重試如何呈現，避免重複干擾 |
| 詳情模型檢視 | 有限角度拖曳傾斜、放手回正；必要時加入輕微指標視差 | 拖曳是否真有檢視用途；點擊、拖動與進入閱讀的關係；是否需要觸控對應操作 |
| 主題或狀態變化 | 若有明確需求，可評估局部色彩過渡或由選中項向外傳遞的變化 | 是否存在相應的主題／狀態操作；色彩是否承載資訊，以及動畫能否幫助理解 |

## 後續取捨原則

- 先定資訊與互動，再定動畫；功能未確定時不先建立動畫框架或擴充設定頁。
- 使用者明確不喜歡懸停文字提示與預覽浮層，已移出候選項；資訊在選中面板或明確點擊後展示，見 [介面偏好](UI_PREFERENCES_ZH.md)。
- 優先改善高頻操作的回應與連續性。新增效果須可中斷、避免排隊，並尊重系統減弱動畫設定。
- 保留現有材質、單一渲染迴圈與自動解析度策略；不恢復「流暢模式」。按採用項目做必要的效能抽查，不為低收益細節反覆調校。
- 長開機演出、完整模型拆解、音樂視覺化等不列入目前文库改進範圍。
