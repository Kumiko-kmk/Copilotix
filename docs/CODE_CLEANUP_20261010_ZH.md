# 2026-10-10 代码清理审计

本轮以 `ui/library-rhinelab` 的 `bbc832a` 为基线。目标是删除已证实无运行用途的代码，减少重复处理，保持现有界面和运行契约。改动独立提交，便于回退。

## 结构与判断依据

现有 Main、Preload、Renderer、Utility、Core、Shared 分层仍有明确职责，不需要整体重构。使用 TypeScript 模块解析检查五个入口：Main、Preload、Renderer、Utility，以及独立卸载 Utility。结合全仓库引用搜索，源模块由 146 个减至 144 个；剩余未从这五个入口到达的 `shared/e2eLaunchPolicy.ts` 被 Electron E2E 使用，保留。

覆盖率用于定位验证薄弱处，不能证明代码无用。原报表只统计 Main、Core、Shared，且排除了 Main 启动等文件；Renderer、Preload、Utility 不在覆盖率分母内。本轮保持统计配置、阈值、测试跳过项和依赖锁文件不变。
