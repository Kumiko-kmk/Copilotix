# Paper Brief v2 維護契約

授權、取消、併發與保存見 [AI 檔案卡](PAPER_INSIGHT_ZH.md)。欄位以 `features/insight/core/paperBrief/schema.ts` 為準，四部分字數以 `archiveLengths.ts` 的 `ARCHIVE_LENGTHS`（由 `lengths.ts` 轉出）為唯一來源，提示詞與新輸出校驗共用。

## 四部分分析

- 詳情依序「摘要 → 背景 → 結論 → 討論」。摘要忠實壓縮研究目的、方法、結果與意義；背景從本文引言／相關工作總結；結論以條目說明核心工作、方法及結果，附可展開的全文分塊證據；討論包含領域貢獻、本文呈現的研究進展、局限與展望。
- 研究進展限於論文寫作時及全文涵蓋的範圍，不代表截至今日的最新進展。作者自述與 AI 推斷在措辭上區分，不能憑模型記憶增加後續文獻。
- 新模型輸出包含分類、總結、關鍵詞、`analysis` 四部分、覆蓋資訊及缺失的首頁 `metadata`；資訊兜底及證據驗證契約見 [首頁事實提取](PAPER_INSIGHT_ZH.md#首頁事實提取)。程序投影舊 v2 必要欄位以維持消費端兼容，不再要求模型生成隱藏的術語／閱讀路線。新舊檔案展示均不再顯示證據基礎／檢驗方式，舊字段僅保留存儲兼容。
- 漢字／全形標點計 1，其餘非空白字元計 0.5。原生解碼另限制摘要不超過 300 個原始字符、引導結論寫向範圍中部；不改舊檔保存契約。四部分單項與合計均校驗；範圍是提示目標，驗收容許上下 15%（首次與修復相同，tldr 等舊欄位亦同；2026-10-22 使用者決定）。一次修復後仍超出時，Codex 改用下一個已啟用的 Qwen／DeepSeek 重新生成，其餘服務商生成失敗，原檔保留。「原文未說明」允許短於下限，不為字數補造內容。
- 摘要及其餘三頁正文統一 16px，摘要維持段落與首行縮排；背景、結論、討論統一三點，短標題＋正文，每點 100–140 字，合計 300–420 字（標題另計）。各點正文首行縮排兩字，點間固定 18px 間距並向上排列，不按面板高度拉開；長內容保持字號並滾動。背景仍存字串，以空行分隔三個「短標題：正文」，舊單段背景按句分組並顯示「領域現狀／已有方法與不足／研究切入點」兜底標題，不回寫源文。結論不顯示通用免責、強度或核對標籤，保留點擊展開的原文依據；具體條件保留在結果中，局限集中於討論。
- 四頁選區共用閱讀器的高亮、下劃線及筆記工具列，不提供加入對話。檔案文字使用 `archive:<頁>:<點>:title/body` 區塊鍵；標註沿用原文產物的 revision／差量 IPC，僅改動 archive 區塊，不刪除正文標註。筆記沿用 `notes.v1.json`，按 archive 錨點獨立顯示；不改 schema、IPC 或資料庫。重新生成後按引文及上下文重定位，無法匹配的標註／筆記保留但不錯配到新文字；切頁清除選區，保存失敗顯示錯誤。舊版仍可讀記錄，找不到 archive 區塊時不繪製。
- 新內容的數學變量／公式使用 LaTeX；顯示仍經 `ArchiveText.tsx`、閱讀器 `prepareReaderMarkdown` 和 KaTeX。舊數學兼容只作用於顯示，不改源文或已存檔案。
- `grounded` 僅表示證據編號存在，`numbersVerified` 僅表示數字匹配，不驗證推論、單位、條件或論文可靠性；核對結果仍保存，結論頁保留條目及原文依據，不另加標籤。

## 全文與請求

- 档案生成改用 `buildFullBriefContext`，完整發送已解析原文；原文缺少／空白才回退譯文。只做可還原的順序分塊及 E1…編號，不選段、不丟參考文獻／附錄、不清理長公式或壓縮表格。圖片保留 Markdown 鏈接，不表示已發送圖片像素或完成視覺分析。
- Utility 通過 `insight:brief-source` 返回已校驗文獻的路徑、雜湊與 revision 小描述符；Main 讀全文，檢查普通文件／大小／SHA-256，讀後重新確認 revision。全文不經 Renderer 或 1 MiB Core RPC 信封，Core RPC 全局上限不變。取消與源文更新不接受半截輸入。
- 原始文本安全上限 16 MiB，序列化模型請求上限 20 MiB；這些是傳輸限制，不是模型 token 上限。超限明示失敗，不截斷、不降回摘錄；所選模型仍須能容納全文及輸出。
- Qwen／DeepSeek 沿用 temperature 0.2、max_tokens 6000 與 JSON 格式；Codex 檔案使用結構化輸出與 medium 檔位，任務最多 10 分鐘。修復只追加一次先前回答與具體問題，仍保留全文並檢查請求上限及授權。
- `buildBriefContext` 的舊選段預算僅保留供其他摘要／分類流程使用，不再是檔案生成入口。

## 兼容與恢復

- 仍保存 `insight/brief.v2.json`，schemaVersion 2。`analysis` 在存儲契約中可選，舊 v2 可讀，按四頁重新歸類並提示缺失的研究進展；舊摘要仍取譯文。無 v2 時保留 v1／結構回退。
- 新生成必須符合四部分輸出契約；舊保存結果不套新字數、不自動重生成、不刪 v1、不改 SQLite migration／備份 manifest。`PAPER_BRIEF_PROMPT_VERSION` 更新後只提示可重新生成。
- 原子保存、源文 revision、取消／刪文獻／維護鎖契約保持原有語義；校驗或生成失敗保留此前檔案。
