# Paper Brief v2 維護契約

生成、校驗與保存已接入；授權、取消、併發與兼容見 [AI 檔案卡](PAPER_INSIGHT_ZH.md)。欄位以 `shared/paperBrief/schema.ts` 為準，字數／數量以 `lengths.ts` 為唯一來源，提示詞與檢查共用，不在文檔複製整張數值表。

## 顯示與校驗

- 選中頁顯示關鍵詞及 `tldr` 總結。詳情標題下為譯文標題；分頁依序「摘要（譯文）→概覽→發現→局限與前提」。閱讀路線與術語僅保留生成／存儲兼容，不在文庫顯示。
- 資訊欄為作者／單位、證據基礎、檢驗方式；概覽含背景、缺口、問題、方法、關鍵思路與貢獻。發現保留結論、證據、強度、適用範圍和可展開的來源摘錄；局限區分作者自述／推斷，並列前提與開放問題。
- 字數：漢字／全形標點計 1，其餘非空白字元計 0.5。只檢查新輸出：首答低於下限 75% 或高於上限 115% 時修復一次；第二答仍做 strict schema 校驗，但不因字數丟棄。
- 「原文未說明」可短於下限，不湊字、不編造；依論文而定的列表只限制上限。存儲 schema 的上限不得收緊而破壞舊結果。
- `assembleBrief` 去重列表、刪除無效 anchor，閱讀路線只保留目錄中的章節；摘錄缺角色或被截斷時標示部分摘錄。
- `grounded` 僅表示引用存在，`numbersVerified` 僅表示數字匹配；不驗證推論、單位、条件或論文可靠性。未通過的發現保留並標「需核對」，強度是模型判斷。

## 摘錄與請求

- Utility `buildBriefContext` 使用 detailed 56 KiB 選段預算，優先原文、缺失時用譯文；按角色、貢獻與數字密度挑選，保持原文順序與 E1…編號，最多 96 段。正文不經 Renderer 轉發。
- 排除圖片路徑、引用標記、長公式、作者／授權頁首及無關章節，表格壓縮為文字；數學中的 `<` 不視為 HTML，保留無摘要標題時的長段摘要回退。
- `buildBriefMessages` 將正文標為不可信資料；temperature 0.2、max_tokens 6000、JSON response_format、非思考模式。完整 HTTP body（含修復對話）≤80 KiB，選段預算與序列化大小分別檢查。
- schema／格式失敗只追加一次截短回答與具體錯誤；重試仍檢查授權及預算。Provider 只在明確拒絕可選參數時省略該參數重送，不改問答預設。
- 修改提示詞、選段或欄位契約時更新 `PAPER_BRIEF_PROMPT_VERSION`；不同版本只提示重新生成，不自動令全庫過期。
