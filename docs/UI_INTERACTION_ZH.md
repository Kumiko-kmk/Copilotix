# Copilotix 桌面端 UI 交互规范

本文档记录已经确认的桌面端交互与尺寸基线。后续设置页 UI 修改必须遵守本文件；如确需调整，应先更新本文件、对应样式和自动化测试，并在同一次提交中说明原因。

## 设置页布局基线

- 设置页保持单页固定高度，内容区不得出现纵向或横向滚动条。
- 窗口高度不足时，优先裁切下方图表区域；服务配置和底部操作区不得因图表而改变既有高度。
- 设置内容容器使用 `width: 100%`、`max-width: 1000px`，所有卡片、图表和底部操作区均以该内容容器为水平基准。

## 底部横向分隔线

设置页底部操作区上沿的横向分隔线是设置页后续改动的统一尺寸基准：

| 项目 | 固定准则 |
| --- | --- |
| CSS 选择器 | `.settings-actions` 的 `border-top` |
| 高度（线宽） | `1 CSS px` |
| 宽度 | 设置内容容器宽度的 `100%`，最大 `1000 CSS px` |
| 水平位置 | 与设置内容容器左右边缘严格对齐，不增加额外左右缩进或负边距 |
| 颜色 | 使用设计令牌 `var(--border)` |
| 操作区最小高度 | `70 CSS px`，分隔线包含在该区域上沿 |

实现基准为：

```css
.settings-content {
  width: 100%;
  max-width: 1000px;
}

.settings-actions {
  min-height: 70px;
  border-top: 1px solid var(--border);
}
```

任何设置页内容即使视觉上只占部分宽度，也不得缩短、加粗或偏移这条分隔线。响应式变化只允许内容容器随可用空间收窄，分隔线始终跟随容器保持 `100%` 宽度和 `1 CSS px` 高度。
