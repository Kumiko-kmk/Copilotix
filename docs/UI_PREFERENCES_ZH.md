# 介面偏好

## Lite 版外殼

專注閱讀的版本（`__COPILOTIX_LITE__`，組裝於 `app/renderer/LiteApp.tsx`）。跳轉與設定比照 agent 程式的對話：不放頂部導覽、文庫、教學與主頁特效。

- 左側欄：「新建」回主頁，一鍵切換、沒有返回鍵；標題最多兩行（不能用懸停看全文），未完成的論文才顯示狀態。可收起（按鈕或 Ctrl+B，輸入中不觸發），儲存於 localStorage `copilotix.lite.sidebar-collapsed.v1`。
- 分組：「置頂」在最上，其下按內容自動分組（`library:categories`，本地計算、不調模型），分組內置頂的論文排在組首並帶小圖釘，其餘新到舊；分類尚未覆蓋的新論文先在「未分組」。只有一組未分類論文時不顯示組名。組名是淡色小標題，懸停或收起時才出現箭頭，點選收起。置頂與收起狀態存 localStorage `copilotix.lite.sidebar-sections.v1`，各視窗同步；全域性置頂與組內置頂互斥。
- 右鍵（或選單鍵）：在新視窗中開啟、分屏開啟、重新命名、置頂、在分組內置頂、刪除。重新命名就地編輯，Enter 或離開儲存、Esc 取消，F2 亦可；刪除沿用閱讀器的確認框；Delete 鍵直接開確認框。
- 分屏：與閱讀器工作臺同一分割線（樣式、拖動、方向鍵），左右各一篇、各自完整的閱讀器，寬度 25%–75%；右側標題欄有「關閉分屏」。側欄點選的論文進入最後使用的一側，該側論文高亮、另一側淡高亮；同一篇不同時出現在兩側。
- 新視窗：無邊框，與主視窗同一 renderer 與 IPC 信任，開啟即顯示該論文；關閉即銷毀（主視窗關閉仍是隱藏）。文庫與背景作業事件廣播到所有視窗。
- 切換：最近 3 篇閱讀器保持掛載（隱藏、`inert`），回去即時；指向論文 120ms 後預讀其內容。
- 匯入單篇直接進入該論文（解析期間可先看 PDF），批次匯入留在主頁，進度看側欄。
- 切換論文後回來，按本次會話記住的 PDF 與原文／譯文位置繼續；不寫磁碟，重啟後從頭開始。
- 設定是浮在應用上的視窗（`SettingsDialog`），隨應用視窗伸縮（880×600 至 1000×760，最小視窗仍為 880×600），不取代頁面：背後的論文變暗但仍可見、保持掛載（`inert`），關閉後位置不變。左側分類配細線條單色圖示（`settingsIcons.tsx`，16px、1.5px 描邊、跟文字同色），右上角關閉；Esc 或點視窗外也會關閉，三者都經未儲存確認。只有三個分類，全部單層，沒有說明文字、子分頁、多金鑰清單或「高階設定」：「服務」一行一個服務（MinerU、千問、DeepSeek、Codex），依次為名稱、金鑰輸入框、測試、刪除、狀態與「用來翻譯」開關；每個服務商只填一把金鑰（存入預設連線），翻譯順序沿用已存順序；Codex 自動偵測程式與預設模型，找不到時才出現「選擇程式」。「儲存」只有儲存位置與匯出／匯入／遷移；「外觀」為六個主題色塊（底色、「文 Aa」、強調色圓點）、字號與行距滑桿和填滿剩餘高度的閱讀範例。儲存欄只在有改動時出現，最小視窗不出現捲動。

## 全應用沿用文庫風格

使用者喜歡文庫的視覺語言，但不要為模仿而堆疊線條與文字。設定、閱讀器、問答與教學已對齊；新介面沿用：

- 層級：頁面標題用 `page-brand` 樣式（英文大寫眉標＋粗黑標題，說明行可選，視窗高度 ≤760px 時隱藏），不要再疊加多餘標籤或提示文字。設定頁例外，見下。
- 分隔：靠留白與柔和的淺色面板（無邊框、圓角 4px）區分割槽塊；不加墨線、方點、虛線行分隔等裝飾線。
- 控制元件：主按鈕為墨色、懸停轉強調色；分頁籤為灰字、選中墨字加強調色下劃線；禁用按鈕保持透明底。全域性 token 在 `main.tsx` 的 `ConfigProvider`。
- 首頁使用 `homeCipher.ts` 解密字陣與動態字標，波浪由 `homeWave.ts` 同步；按字標實測字寬／行高對齊並避開前景塊。開頁、點選或 75–120 秒的自動波單向擴散，波後顯示文庫論文原文或譯文標題；待機保留閃爍與火花。新波到來時上一標題 0.45 秒內淡出，不恢復舊書桌或等高線背景。
- 拉丁文標題不用兩端對齊（短行會被拉開），中文正文與文庫區仍兩端對齊。
- 載入：統一用圖示裡那顆蘋果做的 `AppleLoader`（`platform/ui/renderer`）：強調色蘋果持續翻轉下墜，周圍淡墨豎線向上掠過以顯速度與方向；減少動態時靜止。頁面級 80px 附一行「正在開啟…」，問答等待首字時用 36px 無文字版；不用 antd Spin。
- 問答：問題是右側淺強調色氣泡（常規字重），回答是下方的正文，輪次之間只留白；輪次選單在懸停或聚焦問題時出現。元資訊一行「模型 · 時間 · tokens」。空對話顯示「就這篇論文提問」、一行說明與四張起手問題卡（速覽／方法／證據／延伸），點選只填入輸入框；最新完成的回答下給三個追問膠囊，同樣只填入。

## 設定頁一屏顯示，不出現捲軸

設定的各分頁在最小視窗 1100×700 內完整顯示，不滾動、不裁切。服務連線頁每個服務（MinerU、模型金鑰摘要、Codex）佔一行：左為名稱、其下狀態，右為憑據或程式欄與操作按鈕；Codex 以「驗證連線」合併檢測和模型測試，程式路徑與推理強度收進「高階設定」；模型選擇與狀態保留。API 金鑰頁一次顯示一個服務商，至多 5 個金鑰加新增欄，滿額時禁用新增而不是滾動。用量面板填滿剩餘高度並可壓縮；模型優先順序的請求順序放在標題行，視窗高度 ≤760px 時行距收緊。新增服務或設定項須先確認仍可一屏放下，放不下時調整版面配置而不是加滾動。迴歸入口：`e2e/ui-chrome.spec.ts` 的設定用例（含 5 個金鑰的 API 金鑰頁）在 1440×900 與 1100×700 檢查內容不溢位。

## 設定頁版式

比照 Claude 應用的設定頁：左列分類、右列內容，兩版共用（`features/settings/renderer/settings.css`）。

- 左列：頂部是「設定」標題；分類不編號，前面配細線條單色圖示（`settingsIcons.tsx`），懸停與選中用淺色圓角底。Lite 的設定是浮動視窗，見上文「Lite 版外殼」。
- 右列（完整版整頁）：每塊是一張柔和淺色面板（無邊框、圓角 10px），只放標題、控制元件與必要的狀態或錯誤；不加說明行、副標題、英文小標、「必需／可選」標籤或頁尾提示。時間範圍、匯入遷移會重啟等提示留在圖表本身或確認對話方塊裡。
- 狀態統一為圓點加短字（未配置／待驗證／已驗證／驗證失敗）；輸入框為圓角描邊。API 金鑰的服務商切換用分段按鈕。
- 字級：面板標題 14px 半粗，正文 13–14px，次要數字與狀態 12px；面板間距 8px。

## 設定頁尺寸基線

`.settings-content` 使用 `width: 100%`、`max-width: 1000px`；內容與底部操作區共用水平基準。`.settings-actions` 的上邊線保持 1 CSS px、寬度為容器的 100%，不得增加左右縮排或負邊距，最小高度 70 CSS px。邊線顏色沿用當前 `var(--rule)`；視窗縮小時跟隨容器收窄。服務配置與儲存操作必須保持可用，不以裁切代替最小視窗驗收。

## 顯示草稿與離開確認

設定頁根節點為 .settings-content-body 的直接子元素 .settings-section，填滿可用空間，不重複導覽標題或加專屬外層邊距；卡片邊緣與服務連結頁一致，section／aria-label 保留區域名稱。顯示頁六套主題（三淺三深）只用共用色 token，深色同步 antd darkAlgorithm／color-scheme／陰影；PDF 保持白紙。字號13–22px，行距1.4–2.4、步長0.1、預設1.8，共用預覽。

點選即預覽但只作草稿，儲存才寫 localStorage copilotix.theme.v1／copilotix.reader.font-size.v1／copilotix.reader.line-height.v1；放棄還原，只改外觀不調settings IPC。離開提供「儲存並離開／放棄並離開／繼續編輯」，頁籤切換保留草稿不彈窗；儲存或部分憑據失敗留頁保留失敗欄位，未存Key僅在記憶體。

## 文字兩端對齊

文庫（選中頁、展示檔案頁、搜尋結果、檔案卡內容）的正文統一兩端對齊，段落末行自然左對齊，不強制拉伸短行；逐行遮擋條按實際文字寬度繪製。論文標題、譯文標題與搜尋結果標題左對齊（兩端對齊會把短行拉開）。分類名、操作提示等原本居中的標籤保持居中。

閱讀器原文／譯文正文、列表及 AI 問答的問題／回答正文同樣兩端對齊；標題、程式碼和表格沿用內容排版，不拉伸短標題或資料。

## 不顯示懸停提示

使用者不喜歡懸停說明，包括黑底白字提示、原生 `title`、Tooltip、Popover 預覽和截斷全文浮層。此規則適用於整個應用，不用換顏色或延時替代。必要資訊放在頁面內或由明確點選展示；保留可見標題、`aria-label`、進度、錯誤及操作確認。

僅有兩處例外，均為使用者明確要求，展示的是論文或使用者自己的內容而非說明文字；不得以此為先例給其他控制元件加懸停浮層：

1. 閱讀器便利貼筆記（2026-10-17）：懸停在寫了筆記的文字或頁邊羽毛筆上，約 0.2 秒後顯示該筆記並可直接修改。
2. 正文引用的參考文獻（2026-10-21）：在原文／譯文 Markdown 檢視中，懸停正文引用標記（`[12]`、`[1–3]`、`[12, 15]`、上標數字、`Moraes et al. (2020)` 等）約 0.16 秒後顯示本文參考文獻列表中的對應條目，多條引用列出多條；另一檢視的條目文字不同（參考文獻有譯文）時一併顯示。點選正文標記跳到列表中的該條並短暫高亮；彈窗優先顯示在上方，滑鼠移入彈窗保持顯示，點選條目複製編號之後的內容。邊界：條目只取自論文自身解析出的參考文獻，完全本地、不聯網；對不上（作者年份有歧義、編號超出列表等）就不標記、不顯示，不猜；區間中個別條目在解析結果裡缺失時只註明缺失。只覆蓋正文引用，不給其他文字、連結或控制元件加懸停；不另開參考文獻檢視，不做引用格式轉換。PDF 檢視暫未提供（PdfPane 尚無連結註釋層）。實現見 `readerCitations.ts`（解析）與 `ReaderCitations.tsx`（懸停層）。

閱讀器正文雙擊進入原地編輯，單擊只選段／定位（不顯示編輯按鈕）；PDF 段落框、原文／譯文段落與圖組右鍵開啟同一自繪選單（重新翻譯此段、整段加入對話、刪除／恢復此段；圖組另有加入問答、PDF 原圖／解析子圖切換、在 PDF 中檢視、刪除此圖）。段落與圖片下方不放按鈕或常駐標籤：譯文過期只以淡點線左緣提示，原因在選單首行；工具列不放「已刪除 N 段」。段落與圖片排序靠長按約 0.4 秒後拖動（不放拖動把手），右鍵僅保留「恢復原始順序」，不再提供「上移／下移」，見 [Markdown 格式](MARKDOWN_FORMAT_ZH.md)「閱讀器內編輯與整段刪除」。

Select／Badge 的空 title 用於關閉自動提示，不能刪除；Modal.title、服務卡片 title、表格欄名為可見標題，保留。僅在顯示層移除原文 HTML／公式 title，不改原文、匯出或協定。視窗控制固定於獨立持久標題欄，層級高於彈層且 no-drag；window-controls E2E 驗跨頁／最大化／確認框命中。

## 文庫頁與 AI 解讀

### 資訊與資料

- 圖片 AI 解讀提供 `window.copilotix.figureInsight.get/generate/cancel/onChanged`，模型只返回 `displayWeight`（唯一綜合展示分數）、`overview`、`takeaway`；不加封面評分／理由／supports。每張結果存 `<文獻目錄>/insight/figures/<SHA256(figureId)>.v1.json`，位置、圖片雜湊和來源版本由程式附加；封面依現有結果讀取排序，不觸發生成，尚無獨立解析視窗或自動批次上傳。原 PNG 定位與傳輸 JPEG98 身份須區分；介面、相容、傳輸及驗證邊界只在 [圖片 AI 解讀](FIGURE_INSIGHT_ZH.md) 維護。
- `LibraryPage` 懶載入 Three.js；從文庫進 Reader 用 `returnTo: 'library'` 返回並恢復論文，從教學進入返回教學，其他入口返回首頁。重試與刪除論文在閱讀器頂欄（`DocumentLifecycleActions`）。RhineLabUI 來源與 MIT 許可見 `THIRD_PARTY_NOTICES.md`、`features/library/renderer/archive/RHINELABUI_LICENSE.txt`；GLB 僅五個外殼網格，沿用 inline／parseAsync 和原 CSP。
- 每分類一列，列／行迴圈並記住論文 ID；右下角列數等於分類數，分類名十二字固定寬度居中，箭頭位置固定。分類演算法、分頁與快取只在 [內容分類](LIBRARY_CATEGORIES_ZH.md) 維護。
- 瀏覽標題移除末尾 `.pdf`，固定兩行高度、單行垂直居中、超出省略；譯文標題固定一行，沒有譯文留空。全庫譯名與小型檔案資訊經只讀 catalog 批次取得，任意跨列選中直接顯示，封面另行全庫提前準備，不依賴相鄰位置；不另調模型。
- 選中頁元資訊只含單行關鍵詞（空格分隔，按寬度縮至 11px，仍超出省略）及下方總結（v2 `tldr`／v1 `summary`）；不顯示型別、日期、生成狀態。詳情標題下同樣顯示譯文標題，不重複型別／學科／總結；證據基礎與檢驗方式在新舊檔案展示均不顯示，舊欄位只作儲存相容。
- 詳情 v2 依「摘要／背景／結論／討論」顯示；正文統一 16px、首行縮排兩字，段末行自然左對齊；背景每點顯示短標題，背景／結論／討論各點統一顯示 1、2、3 序號，標題首字與正文首行同為左縮排 32px，不顯示結論頁籤總數；右欄展開前後的標題、作者、正文與橫線同寬，筆記槽在正文外的獨立包絡。新舊檔案均不顯示證據基礎／檢驗方式。選區提供共用高亮、下劃線及筆記，不提供加入對話；archive 區塊鍵與原文隔離，儲存與重定位邊界見 [Paper Brief](PAPER_BRIEF_ZH.md)。新摘要由全文生成，舊檔仍回退譯文，缺失明示；ABSTRACT 不參與遮擋，正文仍沿用解密動畫。詳情延伸至頁面底部，「開啟閱讀」靠下，隱藏捲動條並保留滾輪／鍵盤捲動。生成操作在閱讀器「AI 問答」頁籤工具列的「檔案卡」點選選單。HTTP(S) 連結保留目標、下劃線且可換行。無 v2 時保留結構／舊解讀頁；v2 分頁與生成欄位以 [Paper Brief](PAPER_BRIEF_ZH.md) 為準。
- 生成授權、取消、併發、儲存與相容只在 [AI 檔案卡](PAPER_INSIGHT_ZH.md) 維護。解析完成後與翻譯並行生成，翻譯完成事件補足恢復；自動生成已恆為開啟、不提供開關；使用程式即同意傳送所需內容，不再獨立確認；傳送前仍核對啟用服務、模型與憑據。

### 互動與渲染

- 不改 `archiveMotion.ts` 已校準曲線。單一 rAF、約 60fps，牆鐘待機，失焦／隱藏停渲染；reduced-motion 直接完成動畫（含漣漪增益），解除安裝時釋放 GPU。每幀動畫步長上限 `MAX_STEP_SECONDS` 0.25 秒：舊 0.05 秒上限在軟體渲染下把過場拉長數十倍並以多秒重幀阻塞輸入（1.2.0 CI 點選卡死的實測主因），不得改回。文庫進入許可權由全庫只讀 catalog 的已儲存檔案與工作流判定，與選中次序及封面準備解耦；全庫已成熟論文的完整跨頁封面提前準備並儲存；單個背景重任務讓出互動工作，點開目前論文優先。本次會話已確認的整圖不再逐圖查詢 Main。封面快取與失效只在 [library README](../desktop/src/features/library/README.md) 維護；pdf.js 全應用共用單一 worker（傳入 `worker`，不用會隨文獻銷毀的 `workerPort`）。不得恢復「流暢模式」或材質降檔。
- 瀏覽 DPR ≤1.25／≤3.3M 畫素，透射半解析度、陰影 1024；6 幀超時降解析度 15%（下限 0.55），穩定 240 幀且 8 秒未降再升 8%。保留解析拾取、剔除、共享 instanceMatrix、compileAsync 暖機；途經選中卡漣漪最多 6，升起 4.2／回落 4.5。
- 抽出沿用單一 hero、4.05 升起與 detail 鏡頭；鏡頭 >0.6、升起 >3 才解密。標記以 4.8 倍速、玻璃清除以 2.4 倍速，清除前緣羽化 0.12；`onDecryptReveal` 啟動文字揭開。首頁1600px，完整雙頁提前合成、儲存，並在抽出第一幀前上傳 GPU；動畫期間不替換封面。沒有完成封面的冷檔保持原瀏覽姿態，完整後才起動，不在半途等圖；30秒截止，失敗不展開，Esc／換篇／解除安裝取消並按文件ID／版本拒收晚到結果。ArchiveDetail不再擁有封面生命週期；減少動畫模式同樣先備妥完整畫面。
- `lineRedaction.ts` 等文字與檔案卡載入後揭開；遮擋期間正文以 `data-redacted` 不繪製（面板淡入時不可透出），墨條開始右滑時才恢復。ResizeObserver 首次回報不算版面變化；ResizeObserver／MutationObserver 忽略遮擋層，重新量測所有可見文字（含部分末行），滑出途中版面改變就移除遮擋。逐行退場 0.95 秒，閱讀順序曲線與卡片解密時間不變；reduced-motion 不畫墨條。詳情標題與譯名不遮擋：opening 時捕捉瀏覽面板標題位置與字級，先平移縮放進詳情標題區（延遲 120ms、440ms），其餘內容與遮擋層 460ms 後一起淡入上移（300ms），標題不會穿過墨條；closing 時內容 120ms 淡出、標題 180ms 退回。瀏覽面板的關鍵詞／總結按論文快取且總結固定三行高，返回時面板整體淡入、不重播標題滾動；`returning` 標記跟隨論文 ID 直到換篇，不可用計時器移除（會重播動畫）。標題左對齊。文庫全區文字兩端對齊（居中標籤除外），遮擋條隨之齊整。
- Enter 忽略 repeat，抽出／解密中不進 Reader，完全展開後再次 Enter 或「開啟閱讀」進入；點選已展開封面、Enter 與「開啟閱讀」共用可取消的閱讀器入口：先預載閱讀器（10 秒超時），主場景封面推進／放大 4%（280ms）後切頁，閱讀器淡入 180ms；Esc 取消待完成跳轉，減少動態效果直接切換。預載失敗留在文庫並可重試，不掛載第二個閱讀器或 3D 場景。抽出卡片封面為「首頁＋關鍵圖片」跨頁，選圖與排版見 [圖片 AI 解讀](FIGURE_INSIGHT_ZH.md)「文庫封面」。移動 ≥8px、pointercancel／lostpointercapture 不觸發點選。詳情分頁左右／Home／End 移焦，正文方向鍵保留捲動，僅瀏覽區方向鍵換卡。
- 搜尋按標題／原檔名分詞，最多 40 項；`/` 聚焦，Enter 選首項，Tab 選結果，IME 不誤觸並取消慣性。瀏覽 Esc 先收搜尋；抽出期間檢索收合且 inert、結果關閉，Esc 關詳情並移焦迴文庫。收合 0.24 秒內完成，詳情拉伸延遲 120ms 才到達頂部，兩者不交疊；返回時詳情先淡出，橫線 0.2 秒後展開、文字 0.38 秒後展開。搜尋結果與選中頁關鍵詞／總結載入時淡入；詳情分頁以單一滑動指示線切換。WebGL 失敗仍可搜尋進 Reader。
- `closing` 保留舊文獻／封面／模型：面板 180ms 淡出且 inert，模型／鏡頭 320ms 收回後解除安裝。僅一個待選目標，方向輸入累積、搜尋覆蓋；目標移除即取消，收回中重開同篇接續姿態並清掉待選；reduced-motion 直接收回。
- `entryScanTime` 把入場掃描平段壓至約 0.25 秒；肩部在滑入結束時升起。`ARRAY_SCREEN_SHIFT` 將選中卡移向左下（-4%／10% 視口）；瀏覽／詳情共用 `--archive-panel-left` 與 `--archive-detail-width`。
- `onDetailFrame` 寫入 `--archive-detail-top/height` 供 floor veil 遮蓋陣列；詳情頂端與品牌對齊、底端保留 26px 頁面邊距，分頁高度固定，僅正文捲動。不加裝飾框線；返回按鈕在卡片下方。標題位置必須在 opening 時從仍掛載的瀏覽面板捕捉；reduced-motion 跳過。
- 展開後 ≤8.3M 畫素，用 2 倍顯示器 DPR，放不下回原生 DPR（≤2），透射全解析度；靜止不重繪，收回恢復瀏覽上限。`applyResolution` 只標記，下一幀開頭 `flushResolution` 後立即渲染，禁止在幀間直接改緩衝區尺寸造成空白幀；首頁貼圖按展開後裝置畫素高度重取樣。
