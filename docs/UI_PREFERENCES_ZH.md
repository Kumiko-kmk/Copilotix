# 界面偏好

## 全应用沿用文库风格

用户喜欢文库的视觉语言，但不要为模仿而堆叠线条与文字。设置、阅读器、问答与教程已对齐；新界面沿用：

- 层级：页面标题用 `PageBrand`（英文大写眉标＋粗黑标题，说明行可选，窗口高度 ≤760px 时隐藏），不要再叠加多余标签或提示文字。
- 分隔：靠留白与柔和的浅色面板（无边框、圆角 4px）区分区块；不加墨线、方点、虚线行分隔等装饰线。
- 控件：主按钮为墨色、悬停转强调色；分页签为灰字、选中墨字加强调色下划线；禁用按钮保持透明底。全局 token 在 `main.tsx` 的 `ConfigProvider`。
- 首页使用 `homeCipher.ts` 解密字阵与动态字标，波浪由 `homeWave.ts` 同步；按字标实测字宽／行高对齐并避开前景块。开页、点击或 75–120 秒的自动波单向扩散，波后显示文库论文原文或译文标题；待机保留闪烁与火花。新波到来时上一标题 0.45 秒内淡出，不恢复旧书桌或等高线背景。
- 拉丁文标题不用两端对齐（短行会被拉开），中文正文与文库区仍两端对齐。

## 设置页一屏显示，不出现滚动条

设置的三个分页在最小窗口 1100×700 内完整显示，不滚动、不裁切。每个服务（MinerU、DeepSeek、Qwen、Codex）占一行：名称与标签、凭据或程序栏、操作按钮、状态；Codex 的模型选择与说明只多一行。用量面板填满剩余高度并可压缩；模型优先级的请求顺序放在标题行，窗口高度 ≤760px 时行距收紧。新增服务或设置项须先确认仍可一屏放下，放不下时调整布局而不是加滚动。回归入口：`e2e/ui-chrome.spec.ts` 的两个设置用例在 1440×900 与 1100×700 检查内容不溢出。

## 设置页尺寸基线

`.settings-content` 使用 `width: 100%`、`max-width: 1000px`；内容与底部操作区共用水平基准。`.settings-actions` 的上边线保持 1 CSS px、宽度为容器的 100%，不得增加左右缩进或负边距，最小高度 70 CSS px。边线颜色沿用当前 `var(--rule)`；窗口缩小时跟随容器收窄。服务配置与保存操作必须保持可用，不以裁切代替最小窗口验收。

## 文字两端对齐

文库（选中页、展示档案页、搜索结果、档案卡内容）的正文统一两端对齐：行尾整齐，逐行遮挡条也随之齐整。论文标题、译文标题与搜索结果标题左对齐（两端对齐会把短行拉开）。分类名、操作提示等原本居中的标签保持居中。

阅读器原文／译文正文、列表及 AI 问答的问题／回答正文同样两端对齐；标题、代码和表格沿用内容排版，不拉伸短标题或数据。

## 不显示悬停提示

用户不喜欢悬停说明，包括黑底白字提示、原生 `title`、Tooltip、Popover 预览和截断全文浮层。此规则适用于整个应用，不用换颜色或延时替代。必要信息放在页面内或由明确点击展示；保留可见标题、`aria-label`、进度、错误及操作确认。

仅有两处例外，均为用户明确要求，展示的是论文或用户自己的内容而非说明文字；不得以此为先例给其他控件加悬停浮层：

1. 阅读器便利贴笔记（2026-10-17）：悬停在写了笔记的文字或页边羽毛笔上，约 0.2 秒后显示该笔记并可直接修改。
2. 正文引用的参考文献（2026-10-21）：在原文／译文 Markdown 视图中，悬停正文引用标记（`[12]`、`[1–3]`、`[12, 15]`、上标数字、`Moraes et al. (2020)` 等）约 0.16 秒后显示本文参考文献列表中的对应条目，多条引用列出多条；另一视图的条目文字不同（参考文献有译文）时一并显示。点击标记或卡片中的条目跳到列表中的该条并短暂高亮。边界：条目只取自论文自身解析出的参考文献，完全本地、不联网；对不上（作者年份有歧义、编号超出列表等）就不标记、不显示，不猜；区间中个别条目在解析结果里缺失时只注明缺失。只覆盖正文引用，不给其他文字、链接或控件加悬停；不另开参考文献视图，不做引用格式或复制引文。PDF 视图暂未提供（PdfPane 尚无链接注释层）。实现见 `readerCitations.ts`（解析）与 `ReaderCitations.tsx`（悬停层）。

阅读器的段落编辑与段落操作都是点击入口：当前段落再单击正文进入原地编辑（不显示编辑按钮）；PDF 段落框、原文／译文段落与图组右键打开同一自绘菜单（重新翻译此段、整段加入对话、整段加／取消虚线边界框、删除／恢复此段；图组另有加入问答、PDF 原图／解析子图切换、在 PDF 中查看、删除此图）。段落与图片下方不放按钮或常驻标签：译文过期只以淡点线左缘提示，原因在菜单首行；工具列不放「已删除 N 段」，见 [Markdown 格式](MARKDOWN_FORMAT_ZH.md)「阅读器内编辑与整段删除」。

## 文庫頁與 AI 解讀


### 資訊與資料

- 圖片 AI 解讀提供 `window.copilotix.figureInsight.get/generate/cancel/onChanged`，模型只返回 `displayWeight`（唯一綜合展示分數）、`overview`、`takeaway`；不加封面評分／理由／supports。每張結果存 `<文獻目錄>/insight/figures/<SHA256(figureId)>.v1.json`，位置、圖片雜湊和來源版本由程序附加；封面依現有結果讀取排序，不觸發生成，尚無獨立解析窗口或自動批次上傳。原 PNG 定位與傳輸 JPEG98 身份須區分；接口、兼容、傳輸及驗證邊界只在 [圖片 AI 解讀](FIGURE_INSIGHT_ZH.md) 維護。
- `LibraryPage` 懶載入 Three.js；從文庫進 Reader 用 `returnTo: 'library'` 返回並恢復論文，從教程進入返回教程，其他入口返回首頁。重試與刪除論文在閱讀器頂欄（`DocumentLifecycleActions`）。RhineLabUI 來源與 MIT 許可見 `THIRD_PARTY_NOTICES.md`、`paperArchive/RHINELABUI_LICENSE.txt`；GLB 僅五個外殼網格，沿用 inline／parseAsync 和原 CSP。
- 每分類一列，列／行循環並記住論文 ID；右下角列數等於分類數，分類名十二字固定寬度居中，箭頭位置固定。分類算法、分頁與緩存只在 [內容分類](LIBRARY_CATEGORIES_ZH.md) 維護。
- 瀏覽標題移除末尾 `.pdf`，固定兩行高度、單行垂直居中、超出省略；譯文標題固定一行，沒有譯文留空。停留選中論文 180ms 後讀取，與詳情共用 query cache；不另調模型。
- 選中頁元信息只含單行關鍵詞（空格分隔，按寬度縮至 11px，仍超出省略）及下方總結（v2 `tldr`／v1 `summary`）；不顯示類型、日期、生成狀態。詳情標題下同樣顯示譯文標題，不重複類型／學科／總結；證據基礎與檢驗方式在新舊檔案展示均不顯示，舊字段只作存儲兼容。
- 詳情 v2 依「摘要／背景／結論／討論」顯示；正文統一 16px、首行縮排兩字，背景每點顯示短標題。新舊檔案均不顯示證據基礎／檢驗方式。選區提供共用高亮、下劃線及筆記，不提供加入對話；archive 區塊鍵與原文隔離，保存與重定位邊界見 [Paper Brief](PAPER_BRIEF_ZH.md)。新摘要由全文生成，舊檔仍回退譯文，缺失明示；ABSTRACT 不參與遮擋，正文仍沿用解密動畫。詳情延伸至頁面底部，「打开阅读」靠下，隱藏捲動條並保留滾輪／鍵盤捲動。生成操作在閱讀器「AI 问答」頁籤工具列的「档案卡」點擊選單。HTTP(S) 連結保留目標、下劃線且可換行。無 v2 時保留結構／舊解讀頁；v2 分頁與生成欄位以 [Paper Brief](PAPER_BRIEF_ZH.md) 為準。
- 生成授權、取消、併發、存儲與兼容只在 [AI 檔案卡](PAPER_INSIGHT_ZH.md) 維護。解析完成後與翻譯並行生成，翻譯完成事件補足恢復；自動生成已恆為開啟、不提供開關；使用程序即同意發送所需內容，不再獨立確認；發送前仍核對啟用服務、模型與憑據。
- 發布時間戳由 `runtime-file-times.mjs` 只更新 staging runtime，避免 Electron 資源顯示 1980 年；不修改依賴、內容、簽章或用戶文庫。

### 互動與渲染

- 不改 `archiveMotion.ts` 已校準曲線。單一 rAF、約 60fps，牆鐘待機，失焦／隱藏停渲染；reduced-motion 直接完成動畫（含漣漪增益），卸載時釋放 GPU。每幀動畫步長上限 `MAX_STEP_SECONDS` 0.25 秒：舊 0.05 秒上限在軟體渲染下把過場拉長數十倍並以多秒重幀阻塞輸入（1.2.0 CI 點擊卡死的實測主因），不得改回。選中論文停留 400ms 後才準備圖片／封面（`useArchivePreparation`），快速翻閱不渲染 PDF；本次會話已確認的整圖不再逐圖查詢 Main。封面首頁按 PDF 內容雜湊存於 renderer IndexedDB `copilotix-archive-pages`（≤160 頁，WebP，失敗回退重繪），關鍵圖頁仍按當前整圖與解讀合成；pdf.js 全應用共用單一 worker（傳入 `worker`，不用會隨文獻銷毀的 `workerPort`）。不得恢復「流暢模式」或材質降檔。
- 瀏覽 DPR ≤1.25／≤3.3M 像素，透射半解析度、陰影 1024；6 幀超時降解析度 15%（下限 0.55），穩定 240 幀且 8 秒未降再升 8%。保留解析拾取、剔除、共享 instanceMatrix、compileAsync 暖機；途經選中卡漣漪最多 6，升起 4.2／回落 4.5。
- 抽出沿用單一 hero、4.05 升起與 detail 鏡頭；鏡頭 >0.6、升起 >3 才解密。標記以 4.8 倍速、玻璃清除以 2.4 倍速，清除前緣羽化 0.12；`onDecryptReveal` 啟動文字揭開。首頁 1600px／LRU 6，按需載入 PDF／資料／解讀；換篇或卸載取消晚到結果與訂閱。
- `lineRedaction.ts` 等文字與檔案卡載入後揭開；遮擋期間正文以 `data-redacted` 不繪製（面板淡入時不可透出），墨條開始右滑時才恢復。ResizeObserver 首次回報不算版面變化；ResizeObserver／MutationObserver 忽略遮擋層，重新量測所有可見文字（含部分末行），滑出途中版面改變就移除遮擋。逐行退場 0.95 秒，閱讀順序曲線與卡片解密時間不變；reduced-motion 不畫墨條。詳情標題與譯名不遮擋：opening 時捕捉瀏覽面板標題位置與字級，先平移縮放進詳情標題區（延遲 120ms、440ms），其餘內容與遮擋層 460ms 後一起淡入上移（300ms），標題不會穿過墨條；closing 時內容 120ms 淡出、標題 180ms 退回。瀏覽面板的關鍵詞／總結按論文快取且總結固定三行高，返回時面板整體淡入、不重播標題滾動；`returning` 標記跟隨論文 ID 直到換篇，不可用計時器移除（會重播動畫）。標題左對齊。文庫全區文字兩端對齊（居中標籤除外），遮擋條隨之齊整。
- Enter 忽略 repeat，抽出／解密中不進 Reader，完全展開後再次 Enter 或「打开阅读」進入；點擊已展開封面、Enter 與「打开阅读」共用可取消的閱讀器入口：先預載閱讀器（10 秒超時），主場景封面推進／放大 4%（280ms）後切頁，閱讀器淡入 180ms；Esc 取消待完成跳轉，減少動態效果直接切換。預載失敗留在文庫並可重試，不掛載第二個閱讀器或 3D 場景。抽出卡片封面為「首頁＋關鍵圖片」跨頁，選圖與排版見 [圖片 AI 解讀](FIGURE_INSIGHT_ZH.md)「文庫封面」。移動 ≥8px、pointercancel／lostpointercapture 不觸發點擊。詳情分頁左右／Home／End 移焦，正文方向鍵保留捲動，僅瀏覽區方向鍵換卡。
- 搜尋按標題／原檔名分詞，最多 40 項；`/` 聚焦，Enter 選首項，Tab 選結果，IME 不誤觸並取消慣性。瀏覽 Esc 先收搜尋；抽出期間檢索收合且 inert、結果關閉，Esc 關詳情並移焦回文庫。收合 0.24 秒內完成，詳情拉伸延遲 120ms 才到達頂部，兩者不交疊；返回時詳情先淡出，橫線 0.2 秒後展開、文字 0.38 秒後展開。搜尋結果與選中頁關鍵詞／總結載入時淡入；詳情分頁以單一滑動指示線切換。WebGL 失敗仍可搜尋進 Reader。
- `closing` 保留舊文獻／封面／模型：面板 180ms 淡出且 inert，模型／鏡頭 320ms 收回後卸載。僅一個待選目標，方向輸入累積、搜尋覆蓋；目標移除即取消，收回中重開同篇接續姿態並清掉待選；reduced-motion 直接收回。
- `entryScanTime` 把入場掃描平段壓至約 0.25 秒；肩部在滑入結束時升起。`ARRAY_SCREEN_SHIFT` 將選中卡移向左下（-4%／10% 視口）；瀏覽／詳情共用 `--archive-panel-left` 與 `--archive-detail-width`。
- `onDetailFrame` 寫入 `--archive-detail-top/height` 供 floor veil 遮蓋陣列；詳情頂端與品牌對齊、底端保留 26px 頁面邊距，分頁高度固定，僅正文捲動。不加裝飾框線；返回按鈕在卡片下方。標題位置必須在 opening 時從仍掛載的瀏覽面板捕捉；reduced-motion 跳過。
- 展開後 ≤8.3M 像素，用 2 倍顯示器 DPR，放不下回原生 DPR（≤2），透射全解析度；靜止不重繪，收回恢復瀏覽上限。`applyResolution` 只標記，下一幀開頭 `flushResolution` 後立即渲染，禁止在幀間直接改緩衝區尺寸造成空白幀；首頁貼圖按展開後設備像素高度重採樣。
