# 界面偏好

## 全应用沿用文库风格

用户喜欢文库的视觉语言，首页、任务管理、设置、阅读器、问答与教程均已对齐，新界面也须沿用：

- 层级：英文大写眉标（`.eyebrow`，如 `COPILOTIX / SETTINGS`）＋粗黑标题＋一行灰色说明，页面标题用 `PageBrand`；窗口高度 ≤760px 时隐藏说明行。
- 分隔：用墨线与细线（`--rule-strong`／`--rule`），区块顶部墨线左端带 5px 方点（`ArchiveRule` 或 `::before`），不用圆角卡片、渐变底或大阴影。
- 控件：圆角 2px；主按钮为墨色、悬停转强调色；次要操作为带箭头的下划线链接；分页签与筛选为灰字、选中墨字加强调色下划线；禁用按钮保持透明底。全局 token 在 `main.tsx` 的 `ConfigProvider`。
- 数字：序号与计数用细体等宽数字（`01`、`03 篇论文`），状态用 5px 方点或细进度线，不用圆形徽章。
- 拉丁文标题不用两端对齐（短行会被拉开），中文正文与文库区仍两端对齐。

## 文字两端对齐

文库（选中页、展示档案页、搜索结果、档案卡内容）的文字统一两端对齐，不用左对齐：行尾整齐，逐行遮挡条也随之齐整。分类名、操作提示等原本居中的标签保持居中。

## 不显示悬停提示

用户不喜欢悬停说明，包括黑底白字提示、原生 `title`、Tooltip、Popover 预览和截断全文浮层。此规则适用于整个应用，不用换颜色或延时替代。必要信息放在页面内或由明确点击展示；保留可见标题、`aria-label`、进度、错误及操作确认。

## 已搜集并移除的位置

| 页面 / 区域 | 移除的提示 |
| --- | --- |
| 首页 | COPILOTIX 字标“点击重播”；继续阅读卡片的论文全名 |
| 文库选中页 | 论文标题、译文标题、关键词、总结、右下角分类全文 |
| 展示档案页 | 论文标题、译文标题、作者 / 单位、证据基础、检验方式的全文提示 |
| 任务管理 | 任务名称、翻译进度、打开输出目录、重试、删除；表格省略时自动生成的标题提示 |
| 阅读器 | 分隔条拖动 / 双击说明、视图页签操作说明、关闭 / 恢复视图、滚动同步、还原分组、布局操作、PDF 无法复制说明、选区数量 Badge 提示 |
| 论文问答 | 固定选区的全文提示；服务商和模型的选中项 / 下拉选项自动提示；引用悬停摘录预览 |
| PDF 正文 | 悬停或选中区块时浮出的文本 / 图片 / 表格等类型标签 |
| 设置 | 活动热力图的日期、文档数、页数提示 |
| Markdown / HTML / 公式 | 显示层删除原文 HTML 和公式生成内容中的 `title` 属性，防止内容自带的提示出现 |

引用点击定位、论文打开、字标重播、阅读器布局与快捷键继续保留。PDF 合并标记为常驻状态信息，继续显示。

`Modal.title`、服务卡片 `title` 和表格列名为可见标题，保留。Select 与 Badge 的空 `title` 用于关闭组件自动提示，不能直接删掉，否则组件会以标签或数量重新生成提示。

显示层移除提示，不改论文原文、存储、导出或生成协议。
