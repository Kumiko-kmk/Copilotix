# 文库关系图谱（原型）

演示：把文库论文按“整体相关度”分组，并以 Obsidian 式关系图谱展示。尚未接入应用；本目录只放生成脚本与页面模板，不放论文数据。

```bash
node build-map.mjs <corpus-dir> <manifest.json> <out.json> [page.html]
```

`<corpus-dir>/<documentId>/paper.compat.md` 为解析后的论文，manifest 提供原文标题（用来在参考文献里识别库内论文）。不需要依赖、API 或下载；`page.html` 是由 `graph.html` 生成、内嵌数据的单文件页面（d3 7.9.0 从 cdnjs 加载）。

## 相关度：一个分数同时决定归属与距离

```
相关度 = 0.55 × 内容相似 + 0.25 × 直接引用 + 0.20 × 共同参考文献
```

| 部分 | 演示做法 | 设计理由 |
| --- | --- | --- |
| 内容相似 | 切块 TF-IDF → LSA 24 维；论文向量 = 切块均值（摘要 ×3），减去全库均值后取余弦（负值记 0） | 不减均值时所有论文都偏向“训练、数据、学习”，彼此都很像 |
| 直接引用 | 参考文献按整词匹配库内论文原题；强度 = 1/√(该论文在库内被引次数)，两个方向取大 | 人人都引的基础论文（Attention 被 5 篇引用）不应把论文拉成一组 |
| 共同参考文献 | 库外文献按词集 Jaccard ≥ 0.5 且年份一致判为同一篇；每篇按特异性 log(N/被引篇数) 加权，Salton 余弦归一，0.12 视为满分 | 只有两篇共引的书目比人人都引的 Adam、ResNet 更说明关系 |

- **分组**：每篇保留最强的 4 条（或 ≥0.25 的）关联构成图，在图上做 Louvain 社区发现；扫描分辨率 0.8–3.0，取 3–6 组中模块度最高的划分。14 篇的结果为 5 组、模块度 0.41，且在 0.8–2.0 的分辨率区间内不变。
- **距离**：页面里每一对论文都是一根弹簧，长度与强度随相关度变化（未画出的弱关联也参与），另有可调的“分组聚拢”力；所以屏幕上的远近就是整体相关度，颜色是分组。
- **组名**：c-TF-IDF，只取组内至少两篇共有、且不超过半个文库都在用的词。正式版交给模型命名。

页面：画布节点、悬停高亮邻居（其余淡出）、拖动节点、缩放平移、标签随缩放淡入；右侧设置栏分“筛选／分组／显示／力”；左下卡片显示与最相关几篇的相关度及其构成（内容／引用／共同参考）；可选显示库外共同参考文献（类似 Obsidian 的未解析链接）与引用方向箭头。

局限：TF-IDF/LSA 对清洗规则敏感，组名由关键词拼出不一定通顺；14 篇规模只能说明方法可行，不能当分组质量的证据。

## 正式方案建议

1. **内容向量**：以 Paper Brief v2 的 tldr、领域、关键思路、贡献、关键词与摘要拼成主题文本做一次嵌入（多语种模型，可复用已配置的 Qwen 凭证）；切块向量与 RAG 共用，作辅助。没有档案卡时退回标题 + 摘要。
2. **引用**：解析参考文献，优先用 DOI／arXiv ID 匹配，其次标题；库外文献合并为稳定的“引用实体”，供共同参考与以后的推荐使用。
3. **权重**：三部分权重做成设置项，默认如上；在真实文库上请使用者抽查若干组后再定。
4. **稳定**：组有持久 ID。新论文按与各组的平均相关度归入（低于阈值进“待归类”）；只有使用者点“重新整理”或变动累积过大才重新分组，并按成员重叠对齐旧 ID，避免文库列反复跳动。手动移动或钉住的论文作为约束保留。
5. **工程**：Utility 的 compute 通道计算；文库级 revision 化产物（向量、引用实体、相关度、分组、布局），Main 只传 ID 与分页结果；备份与卸载清单同步登记。
6. **界面**：文库页增加“按月份 / 按分组”排列，分组即列；图谱作为文库的第二个视图，点击论文回到三维档案并抽取该篇。
