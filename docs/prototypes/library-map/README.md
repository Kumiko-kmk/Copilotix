# 文库地形图（原型）

演示：把文库论文按内容分组，并画成一张能看出主题、相似度与引用关系的地图。尚未接入应用；本目录只放生成脚本与页面模板，不放论文数据。

```bash
node build-map.mjs <corpus-dir> <manifest.json> <out.json> [page.html]
```

`<corpus-dir>/<documentId>/paper.compat.md` 为解析后的论文，manifest 提供原文标题（用来在参考文献里找库内互引）。不需要依赖、API 或下载；`page.html` 是内嵌数据的单文件页面（d3 7.9.0 从 cdnjs 加载）。

## 演示管线（2026-10-10，14 篇真实论文）

| 步骤 | 演示做法 | 结果 |
| --- | --- | --- |
| 切块 | 去掉参考文献、附录、致谢、表格与公式，按段落合并到约 520 字 | 约 540 块 |
| 分词 | 拉丁词 + `Intl.Segmenter('zh')` 中文词；未成词的短单字串整体保留（傅里叶、马尔可夫链） | 约 3100 词 |
| 向量 | 切块 TF-IDF → 随机化 SVD（LSA，24 维）；论文向量 = 切块均值（摘要 ×3），再减去全库均值 | |
| 分组 | 平均链接层次聚类（余弦）；岛数取轮廓系数最高，区域数 ≈ √(n/1.5) 且由同一棵树合并 | 4–5 个主题岛 / 3 个区域 |
| 命名 | c-TF-IDF：只取在主题内至少两篇出现、且不超过半个文库都在用的词 | 例：算子 / pde / deeponet |
| 引用 | 每条参考文献按整词匹配库内论文原题（≥4 词时覆盖 85%，否则须为连续短语） | 17 条 |
| 检索 | 问题按同样分词，折叠进 LSA 空间，与切块余弦排序 | 页面“问文库” |

局限：TF-IDF/LSA 对清洗规则敏感，调整表格清理后 Transolver 在“注意力”与“算子”两个岛之间换边；14 篇的轮廓系数只有 0.2–0.26，说明边界本来就模糊。演示只用来看形态和交互，不能当分类质量的证据。

## 正式方案建议

1. **文档向量**：主信号用 Paper Brief v2 的 tldr、领域、关键思路、贡献、关键词与摘要拼成“主题文本”，每篇一次嵌入；切块向量（与 RAG 共用）取均值作辅助。没有档案卡时退回标题 + 摘要。模型可复用已配置的 Qwen 凭证（DashScope 文本嵌入，多语种），离线场景另评估本地模型的体积。
2. **两层分组**：区域就是文库页的一列（3–8 列），主题岛是列内分段。200 篇以内用层次聚类；更大的库先降维再用 HDBSCAN，噪声点进入“待归类”。
3. **稳定**：主题有持久 ID。新论文按最近质心归入（相似度低于阈值则进“待归类”）；只有用户点“重新整理”或累计变动过大才全量重聚，并按成员重叠把新簇对齐旧 ID，避免列反复跳动。用户手动移动或钉住的论文作为约束保留。
4. **命名**：c-TF-IDF 关键词 + 代表论文的档案卡交给模型，生成 2–6 字主题名与一句说明；成员变化超过约 30% 才重命名。
5. **关系**：语义近邻（文档向量 kNN）、库内引用（参考文献匹配标题，有 DOI 时优先 DOI）、共用方法或数据集（来自档案卡字段）。
6. **工程**：Utility 的 compute 通道计算；文库级 revision 化产物（向量、主题、布局），Main 只传 ID 与分页结果；备份与卸载清单同步登记。
7. **界面**：文库页增加“按月份 / 按主题”排列；地图可作为文库的第二视图，点击论文回到三维档案并抽取该篇。
