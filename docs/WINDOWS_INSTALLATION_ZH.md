# Windows 安装、升级与卸载

## 首次安装

在 [GitHub Releases](https://github.com/Kumiko-kmk/Copilotix/releases) 下载对应版本的 `Copilotix-<版本>-win-x64.zip`，完整解压后双击顶层 `Copilotix-Setup-<版本>-x64.exe`，运行引导式安装精灵。也可单独下载同名 Setup。安装范围为当前 Windows 用户，默认放入用户的程序目录，也可选择其他可写目录。需要管理员权限的系统目录不适合此安装范围。

统一 ZIP 是发布交付范本，解压后所有入口集中在同一个目录：

```text
Copilotix-<版本>-win-x64/
  Copilotix-Setup-<版本>-x64.exe  ← 安装入口
  uninstall.exe                 ← 找到实际安装位置并启动卸载
  安装说明.txt
  advanced/                     ← 小型清单与校验文件
```

完整程序已压缩在 Setup 内，离线安装即可解压到所选目录。交付 ZIP 不再重复附带未安装程序或便携 ZIP，体积约 94 MiB。

安装精灵允许选择安装位置，并创建桌面和开始菜单的 Copilotix 启动入口。安装后使用这些入口启动。安装目录包含完整 Electron 运行文件，不要单独搬走 `Copilotix.exe`。

首次启动后在「设置 → 服务连接」配置 MinerU Token，测试连接并保存。解析与翻译服务的配置和使用教程见 [README](../README.md#api-keys)。

## 位置与个人数据

| 内容 | 位置与管理方式 |
| --- | --- |
| 程序、DLL、资源和卸载程序 | 安装精灵中选择的安装目录 |
| 设置、数据库与凭据相关用户状态 | `%APPDATA%\Copilotix-Translation-v2`；凭据由系统凭据存储保护 |
| 原文、翻译、批注等文档库产物 | 原有「设置 → 文件存储」配置的路径 |

更改安装位置不会迁移文档库。迁移或备份文档库请使用应用的 [文档库管理](LIBRARY_MANAGEMENT_ZH.md)，先等待任务结束。

## 覆盖升级与从 ZIP 转换

1. 等待排队、解析与翻译任务完成；需要备份时先创建文档库备份。
2. 通过托盘菜单退出 Copilotix。关闭窗口可能仅隐藏到托盘；安装器发现仍运行的程序时应先退出再重试。
3. 运行新版 Setup，沿用已有安装位置，完成安装后启动。
4. 检查原任务列表、文档、设置和凭据可用。

从免安装 ZIP 改用 Setup 时，同一 Windows 用户的个人数据位置保持不变，无需复制数据库或密钥。先退出旧版本，再安装和启动；安装版与 ZIP 版共用数据，单实例限制避免两者同时操作文档库。确认新版可用后，可删除旧 ZIP 解压的完整程序目录。

## 卸载与重装

先等待任务结束并从托盘退出，再运行交付包顶层的 `uninstall.exe`。该入口只读取当前用户的 Copilotix 安装登记，然后运行实际安装目录中的卸载精灵，支持本版本 `uninstall.exe` 及旧版 `Uninstall Copilotix.exe`；它不会自行删除下载目录。也可直接运行安装目录中的 `uninstall.exe`，或从 Windows「设置 → 应用 → 已安装的应用」选择 Copilotix 卸载。安装目录中的卸载器依赖安装位置，不要将它单独移出；交付包中的卸载入口可随整个交付包保留。

卸载精灵默认不勾选清除选项，只移除程序、快捷方式与卸载登记，保留设置、凭据、任务数据库及文档库。重新安装并以相同 Windows 用户启动时继续使用这些数据。

如需一并移除文库与资料，请勾选「移除文库、设置与已保存凭据」。随后会再次显示应用资料位置、登记的文档数量及文档目录，只有确认「永久移除」才会清理。清理包括登记在当前数据库中的文档目录、`%APPDATA%\Copilotix-Translation-v2` 内的数据库／设置／日志／缓存／内部恢复备份，以及本项目的已保存 API 凭据。此操作无法恢复，请事先导出需要保留的内容。

自定义文库根目录可能同时包含其他文件，卸载器只清除当前数据库登记的 `documents-v2/<文档ID>` 目录，不会递归删除整个根目录。外部原始来源 PDF、另存的导出文件、外部备份、迁移后保留的旧库与未登记的残留目录保留。路径含符号链接／junction、数据库损坏或清理失败时停止卸载并提示；取消第二次确认同样停止卸载，程序仍可保留以便处理。

覆盖升级及静默卸载不触发资料清理，避免自动升级误删。新的清除选项需安装本版本 Setup 后，才会出现在安装目录中的新卸载器。

旧免安装版本不会注册安装登记。退出应用后删除其完整程序目录即可移除该副本，个人数据同样保留。没有 Setup 安装时，顶层卸载入口会说明未找到安装，不会猜测删除路径。卸载安装版后，下载的 ZIP 和解压交付包仍可保留以便重装；不需要时手动删除即可。

## 验证范围

发布前应在 Windows x64 环境验证首次安装、带空格和中文的自定义目录、桌面及开始菜单快捷方式、覆蓋升级、程序在托盘运行时拒绝或提示退出、卸载后个人数据保留及重装读取，并检查内置教程、导入和阅读。自动化测试结果与当前已完成的验证见 [发布文档](DESKTOP_RELEASE_ZH.md)；本文描述预期契约，不代表所有人工场景已经通过。
