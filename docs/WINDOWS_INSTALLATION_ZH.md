# Windows 安裝、升級與解除安裝

## 首次安裝

在 [GitHub Releases](https://github.com/Kumiko-kmk/Copilotix/releases) 下載 `setup.exe`，直接執行引導式安裝精靈。安裝範圍為當前 Windows 使用者，預設放入使用者的程式目錄，也可選擇其他可寫目錄。需要管理員許可權的系統目錄不適合此安裝範圍。

從 1.2.0 起，公開 Release 僅提供安裝包和 GitHub 自動生成的原始碼下載；無需下載 ZIP、SHA 或清單檔案。完整程式已內嵌在 Setup 中，可離線安裝。

本地開發及 CI 仍保留緊湊 ZIP 用於內部核驗，其版面配置為：

```text
Copilotix-<版本>-win-x64/
  setup.exe  ← 安裝入口
  uninstall.exe                 ← 找到實際安裝位置並啟動解除安裝
  安裝說明.txt
  advanced/                     ← 小型清單與校驗檔案
```

上述 ZIP 不再作為公開 Release 的下載項。普通使用者執行 Setup 即可。

安裝精靈允許選擇安裝位置。“建立桌面圖示”預設勾選，可取消；開始選單也提供 Copilotix 啟動入口。安裝後使用這些入口啟動。安裝目錄包含完整 Electron 執行檔案，不要單獨搬走 `Copilotix.exe`。

首次啟動後，在「設定 → 服務連線」設定 MinerU Token，測試連線後儲存。解析與翻譯服務的詳細步驟見[服務設定](wiki/Service-Setup.md)。

## 位置與個人資料

| 內容 | 位置與管理方式 |
| --- | --- |
| 程式、DLL、資源和解除安裝程式 | 安裝精靈中選擇的安裝目錄 |
| 設定、資料庫與憑據相關使用者狀態 | `%APPDATA%\Copilotix-Translation-v2`；憑據由系統憑據儲存保護 |
| 原文、翻譯、批註等文件庫產物 | 原有「設定 → 檔案儲存」配置的路徑 |

更改安裝位置不會遷移文件庫。遷移或備份文件庫請使用應用的 [文件庫管理](LIBRARY_MANAGEMENT_ZH.md)，先等待任務結束。

## 覆蓋升級與從 ZIP 轉換

1. 等待排隊、解析與翻譯任務完成；需要備份時先建立文件庫備份。
2. 透過托盤選單退出 Copilotix。關閉視窗可能僅隱藏到托盤；安裝程式發現仍執行的程式時應先退出再重試。
3. 執行新版 Setup，沿用已有安裝位置，完成安裝後啟動。
4. 檢查文庫、文件、聊天、筆記、設定和憑據可用。

從免安裝 ZIP 改用 Setup 時，同一 Windows 使用者的個人資料位置保持不變，無需複製資料庫或金鑰。先退出舊版本，再安裝和啟動；安裝版與 ZIP 版共用資料，單例項限制避免兩者同時操作文件庫。確認新版可用後，可刪除舊 ZIP 解壓的完整程式目錄。

## 解除安裝與重灌

先等待任務結束並從托盤退出，再從 Windows「設定 → 應用 → 已安裝的應用」選擇 Copilotix 解除安裝，也可執行安裝目錄中的 `uninstall.exe`。安裝目錄中的解除安裝程式依賴安裝位置，不要將它單獨移出。舊交付 ZIP 頂層的 `uninstall.exe` 仍可讀取當前使用者的安裝登記並啟動實際解除安裝精靈；它不會自行刪除下載目錄。

解除安裝精靈預設不勾選清除選項，只移除程式、捷徑與解除安裝登記，保留設定、憑據、任務資料庫及文件庫。重新安裝並以相同 Windows 使用者啟動時繼續使用這些資料。

如需一併移除文庫與資料，請勾選「移除文庫、設定與已儲存憑據」。隨後會再次顯示應用資料位置、登記的文件數量及文件目錄，只有確認「永久移除」才會清理。清理包括登記在當前資料庫中的文件目錄、`%APPDATA%\Copilotix-Translation-v2` 內的資料庫／設定／日誌／快取／內部恢復備份，以及本專案的已儲存 API 憑據。此操作無法恢復，請事先匯出需要保留的內容。

自定義文庫根目錄可能同時包含其他檔案，解除安裝程式只清除當前資料庫登記的 `documents-v2/<文件ID>` 目錄，不會遞迴刪除整個根目錄。外部原始來源 PDF、另存的匯出檔案、外部備份、遷移後保留的舊庫與未登記的殘留目錄保留。路徑含符號連結／junction、資料庫損壞或清理失敗時停止解除安裝並提示；取消第二次確認同樣停止解除安裝，程式仍可保留以便處理。

覆蓋升級及靜默解除安裝不觸發資料清理，避免自動升級誤刪。新的清除選項需安裝本版本 Setup 後，才會出現在安裝目錄中的新解除安裝程式。

舊免安裝版本不會註冊安裝登記。退出應用後刪除其完整程式目錄即可移除該副本，個人資料同樣保留。沒有 Setup 安裝時，頂層解除安裝入口會說明未找到安裝，不會猜測刪除路徑。解除安裝安裝版後，下載的 ZIP 和解壓交付包仍可保留以便重灌；不需要時手動刪除即可。

## 驗證範圍

釋出前應在 Windows x64 環境驗證首次安裝、帶空格和中文的自定義目錄、桌面及開始選單捷徑、覆蓋升級、程式在托盤執行時拒絕或提示退出、解除安裝後個人資料保留及重灌讀取，並檢查內建教學、匯入和閱讀。自動化測試結果與當前已完成的驗證見 [釋出文件](DESKTOP_RELEASE_ZH.md)；本文描述預期契約，不代表所有人工場景已經透過。
