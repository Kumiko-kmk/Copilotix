# 常见问题

**适用版本：1.1.0。** 先查看任务错误与服务状态，再按以下步骤排查。

## 安装与升级

| 问题 | 检查或操作 |
| --- | --- |
| Windows 提示发布者未知 | 1.1.0 是经授权的未签章发布；确认下载自本仓库 Release 并核对 SHA-256，见[安装指南](https://github.com/Kumiko-kmk/Copilotix/wiki/Installation-and-Upgrade) |
| 只下载 `setup.exe` 能安装吗？ | 可以，独立 Setup 已内嵌完整程序 |
| 只复制 `Copilotix.exe` 无法运行 | 开发副本依赖完整 `program/` 目录，保留 DLL、PAK 与资源，或使用正式 Setup |
| 升级提示程序仍运行 | 等待任务结束，从系统托盘退出；关闭窗口可能只隐藏到托盘 |
| 卸载会删除聊天吗？ | 默认保留；只有勾选清理并二次确认才删除相应个人资料 |

## 解析与翻译

| 问题 | 检查或操作 |
| --- | --- |
| 无法开始解析 | MinerU Token 是否验证且保存；PDF 是否超过本地 200 MiB／600 页限制；服务额度与网络是否正常 |
| Token 测试失败 | 只填 Token 本身，不加 `Bearer`；检查有效期、平台与网络 |
| 测试成功后仍不能用 | 仍需点击「保存全部更改」，再确认已启用相应来源 |
| Qwen Key 正确却不可用 | 核对地域、当前 DashScope 地址、业务空间与模型权限，见[服务配置](https://github.com/Kumiko-kmk/Copilotix/wiki/Service-Setup) |
| 没有 Qwen／DeepSeek Key | 可用已启用的 Bing／TranSmart 翻译，但它们需网络且依赖第三方网页接口，不能用于论文问答 |
| 部分文字仍为原文 | 查看任务是否「部分完成」并重试失败部分；公式、代码等保护内容也可能维持原文 |
| 列表中的模型无法调用 | 列表是版本内置选择项，实际服务权限、模型可用性与余额以账号和服务商为准 |
| 能直接导入 Markdown 吗？ | 当前正式导入格式为 PDF；Markdown 是解析、翻译和导出产物 |

## 阅读工作台与问答

| 问题 | 检查或操作 |
| --- | --- |
| 找不到原文／中文／问答页签 | 可能移到其他分组或已关闭，使用「+」或 `Ctrl+1–4` 打开 |
| 最大化后看不到其他视图 | 按 `Esc` 还原，或双击页签／使用 `Ctrl+Shift+M` |
| 为什么 PDF 没跟着译文滚动？ | PDF 默认关闭同步，可在分组标题栏开启；只有选中可见页签参与，且需要可信内容映射 |
| PDF 里仍有白边 | 应用额外外框与页间留白已移除，但原 PDF 自身的页内白边保留，不会裁切论文版式 |
| 为什么不再有 JSON 视图？ | 1.1.0 只展示 PDF、原文、中文、问答；底层版面文件仍在本地 |
| 旧表格没恢复合并结构 | 旧版已生成的平面表格不会自动修复，也不会自动重解析／重翻译；新阅读保留已有 HTML／LaTeX 结构 |
| 问答无法发送 | 启用且验证 Qwen／DeepSeek、保存设置，等待解析与本地索引完成，并确认发送授权 |
| 添加到对话后页面没有切换 | 加入选区不会自动切走阅读页签，请主动打开「AI 问答」 |
| 重开后聊天会清空吗？ | 不会；轮次、草稿、选区与模型保存在该文献 `chat/` 下 |
| 自定义模型入口在哪里？ | 已移除，只支持预设；旧选择回退，历史轮次保留 |
| 清空对话会删掉论文吗？ | 不会，清除对话轮次，保留草稿、选区、模型及文献产物 |
| 撤销授权能删除服务商数据吗？ | 不能，只撤销后续发送授权并停止当前请求；不远程删除已经收到的数据 |

更多操作见[阅读工作台](https://github.com/Kumiko-kmk/Copilotix/wiki/Reader-Workbench)与[论文 AI 问答](https://github.com/Kumiko-kmk/Copilotix/wiki/Paper-AI-Chat)。

## 文件、导出与备份

| 问题 | 检查或操作 |
| --- | --- |
| 修改保存位置后旧文献没搬过去 | 新位置只影响新任务，使用文库迁移搬移旧库 |
| 分享 Markdown 后图片打不开 | 同时保留相邻图片目录及相对路径，或导出结果 ZIP |
| ZIP 会带上聊天吗？ | 会，已有 `chat/` 也导出，分享前检查问题、回答、草稿与选区 |
| ZIP 能恢复完整文库吗？ | 不能，它不含应用数据库、系统凭据或全部应用状态；使用完整文库备份 |
| 另一台电脑恢复后服务不可用 | 备份不包含系统 API 凭据，请重新配置并验证 |

文件结构和完整流程见[本地资料与导出](https://github.com/Kumiko-kmk/Copilotix/wiki/Local-Data-and-Export)。

## 如何反馈

一般问题请到 [GitHub Issues](https://github.com/Kumiko-kmk/Copilotix/issues) 提供应用版本、Windows 版本、复现步骤、预期行为与脱敏错误信息。截图前检查凭据、聊天、个人路径及未公开论文内容。

安全漏洞按仓库 [Security Policy](https://github.com/Kumiko-kmk/Copilotix/blob/master/docs/SECURITY.md) 报告，不发到公开 Issue。付费模型回答质量和具体硬件差异需实际服务及设备验证，界面截图与 CI 不能替代。
