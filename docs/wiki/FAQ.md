# 常見問題

**適用版本：1.2.0。** 先檢視任務錯誤與服務狀態，再按以下步驟排查。

## 安裝與升級

| 問題 | 檢查或操作 |
| --- | --- |
| Windows 提示釋出者未知 | 未簽章安裝包可能出現此提示；簽章狀態以對應 Release 說明為準，確認下載自本倉庫，見[安裝指南](https://github.com/Kumiko-kmk/Copilotix/wiki/Installation-and-Upgrade) |
| 只下載 `setup.exe` 能安裝嗎？ | 可以，獨立 Setup 已內嵌完整程式 |
| 只複製 `Copilotix.exe` 無法執行 | 開發副本依賴完整 `program/` 目錄，保留 DLL、PAK 與資源，或使用正式 Setup |
| 升級提示程式仍執行 | 等待任務結束，從系統匣退出；關閉視窗可能只隱藏到托盤 |
| 解除安裝會刪除聊天嗎？ | 預設保留；只有勾選清理並二次確認才刪除相應個人資料 |

## 解析與翻譯

| 問題 | 檢查或操作 |
| --- | --- |
| 無法開始解析 | MinerU Token 是否驗證且儲存；PDF 是否超過本地 200 MiB／600 頁限制；服務額度與網路是否正常 |
| Token 測試失敗 | 只填 Token 本身，不加 `Bearer`；檢查有效期、平臺與網路 |
| 測試成功後仍不能用 | 仍需點選「儲存全部更改」，再確認已啟用相應來源 |
| Qwen Key 正確卻不可用 | 核對地域、當前 DashScope 地址、業務空間與模型許可權，見[服務配置](https://github.com/Kumiko-kmk/Copilotix/wiki/Service-Setup) |
| 沒有 Qwen／DeepSeek Key | 可用已啟用的 Bing／TranSmart 翻譯，但它們需網路且依賴第三方網頁介面，不能用於論文問答 |
| 部分文字仍為原文 | 檢視任務是否「部分完成」並重試失敗部分；公式、程式碼等保護內容也可能維持原文 |
| 列表中的模型無法呼叫 | 列表是版本內建選擇項，實際服務許可權、模型可用性與餘額以帳號和服務商為準 |
| 能直接匯入 Markdown 嗎？ | 當前正式匯入格式為 PDF；Markdown 是解析、翻譯和匯出產物 |

## 閱讀工作台與問答

| 問題 | 檢查或操作 |
| --- | --- |
| 找不到原文／中文／問答頁籤 | 可能移到其他分組或已關閉，使用「+」或 `Ctrl+1–4` 開啟 |
| 最大化後看不到其他檢視 | 按 `Esc` 還原，或雙擊頁籤／使用 `Ctrl+Shift+M` |
| 為什麼 PDF 沒跟著譯文滾動？ | PDF 預設關閉同步，可在分組標題欄開啟；只有選中可見頁籤參與，且需要可信內容對映 |
| PDF 裡仍有白邊 | 應用額外外框與頁間留白已移除，但原 PDF 自身的頁內白邊保留，不會裁切論文版式 |
| 為什麼不再有 JSON 檢視？ | 1.1.0 只展示 PDF、原文、中文、問答；底層版面檔案仍在本地 |
| 舊表格沒恢復合併結構 | 舊版已生成的平面表格不會自動修復，也不會自動重解析／重翻譯；新閱讀保留已有 HTML／LaTeX 結構 |
| 問答無法傳送 | 啟用且驗證 Qwen／DeepSeek、儲存設定，等待解析與本地索引完成，並確認傳送授權 |
| 新增到對話後頁面沒有切換 | 加入選區不會自動切走閱讀頁籤，請主動開啟「AI 問答」 |
| 重開後聊天會清空嗎？ | 不會；輪次、草稿、選區與模型儲存在該文獻 `chat/` 下 |
| 自定義模型入口在哪裡？ | 已移除，只支援預設；舊選擇回退，歷史輪次保留 |
| 清空對話會刪掉論文嗎？ | 不會，清除對話輪次，保留草稿、選區、模型及文獻產物 |
| 撤銷授權能刪除服務商資料嗎？ | 不能，只撤銷後續傳送授權並停止當前請求；不遠端刪除已經收到的資料 |

更多操作見[閱讀工作台](https://github.com/Kumiko-kmk/Copilotix/wiki/Reader-Workbench)與[論文 AI 問答](https://github.com/Kumiko-kmk/Copilotix/wiki/Paper-AI-Chat)。

## 檔案、匯出與備份

| 問題 | 檢查或操作 |
| --- | --- |
| 修改儲存位置後舊文獻沒搬過去 | 新位置只影響新任務，使用文庫遷移搬移舊庫 |
| 分享 Markdown 後圖片打不開 | 同時保留相鄰圖片目錄及相對路徑，或匯出結果 ZIP |
| ZIP 會帶上聊天嗎？ | 會，已有 `chat/` 也匯出，分享前檢查問題、回答、草稿與選區 |
| ZIP 能恢復完整文庫嗎？ | 不能，它不含應用資料庫、系統憑據或全部應用狀態；使用完整文庫備份 |
| 另一臺電腦恢復後服務不可用 | 備份不包含系統 API 憑據，請重新配置並驗證 |

檔案結構和完整流程見[本地資料與匯出](https://github.com/Kumiko-kmk/Copilotix/wiki/Local-Data-and-Export)。

## 如何反饋

一般問題請到 [GitHub Issues](https://github.com/Kumiko-kmk/Copilotix/issues) 提供應用版本、Windows 版本、復現步驟、預期行為與脫敏錯誤資訊。截圖前檢查憑據、聊天、個人路徑及未公開論文內容。

安全漏洞按倉庫 [Security Policy](https://github.com/Kumiko-kmk/Copilotix/blob/master/docs/SECURITY.md) 報告，不發到公開 Issue。付費模型回答質量和具體硬體差異需實際服務及裝置驗證，介面截圖與 CI 不能替代。
