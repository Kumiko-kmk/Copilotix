# 🎉 Copilotix 1.2.0：文库档案与阅读笔记

Copilotix 是一款面向论文阅读的 Windows 桌面应用，将 PDF 解析、中文翻译、原文对照与论文问答整合在同一工作区。1.2.0 加入可浏览、检索和展开的文库档案，按摘要、背景、结论、讨论整理论文，并将高亮、下划线和笔记带到档案展示页；同时加入 Codex 服务连接与主题外观设置，改善图表、翻译和阅读体验。

> ⚠️ **此版本经维护者授权，以未签章形式发布。** Windows 可能显示发布者未知或安全提示，请从本仓库 Release 下载。此授权仅适用于 1.2.0，后续版本仍按正式签章政策执行。

## ✨ 本次更新

- 🗂️ **文库档案**：按论文内容分类浏览，支持标题检索、方向键及滚轮切换。展开档案后查看摘要、背景、结论和讨论，点击封面、「打开阅读」或再次按 Enter 进入阅读器；返回文库时保留所选论文。
- 📄 **四部分解读**：档案生成使用完整的已解析论文文本，原文缺少时才使用译文。背景、结论和讨论统一为三点，配有短标题；正文统一字号、首行缩排与点间距，结论可展开原文依据。
- 📝 **标注与笔记**：原文、中文及档案展示页支持高亮、下划线和阅读笔记，随文献保存在本地。档案页选区工具只提供这三项操作；阅读器仍可将选区加入问答。
- 💬 **Codex 与论文问答**：可连接本机已登录的 Codex，按账号可用模型选择翻译与问答服务；支持逐轮操作与随问题保存的阅读选区，重新打开后恢复对话和草稿。
- 🖼️ **图表与封面**：改善多子图归组，保留整图及图内文字的对应关系；档案封面展示论文首页与关键图表，已有图片解读用于封面排序。
- 🎨 **主题与排版**：加入三套浅色、三套深色主题及阅读字号设置，沿用统一的保存与放弃更改流程。首页字阵、文库解密与进入阅读器的过渡保持一致，减少动态效果设置继续生效。
- ⚡ **处理与界面整理**：改善翻译调度、任务恢复和文库准备状态，移除旧任务列表、档案拆解入口及相关资源；阅读与导出的表格、公式和图片继续保留。

## 📥 下载与安装

Windows x64 用户下载本 Release 的 `setup.exe`，运行安装向导即可。完整程序已内嵌，无需另外下载运行目录。源代码可通过下方的 **Source code** 下载。

从本版本起，Release 仅提供安装包及源代码下载；校验信息保留在构建流程内部，不再作为单独下载文件发布。

## ⚙️ 首次使用与服务配置

在「设置 → 服务连接」配置 MinerU Token 和需要使用的翻译／问答服务，验证后保存。使用 Codex 时，先完成本机账号登录，再在应用中选择可用模型；安装包不包含 API 密钥或已登录账号。

正式导入格式仍为 PDF。解析会上传 PDF 至配置的 MinerU 服务；翻译和问答向所选服务发送相关文本。档案卡在解析后自动生成，使用完整的已解析文本；图片解读发送对应图片。服务费用、额度与模型可用性以对应账号为准；档案中的分析与数值仍应结合原文核对。

## 🔄 从 1.1.0 升级

等待后台任务结束，建议先备份文库，再从系统托盘退出 Copilotix，运行新版本 Setup 完成覆盖安装。升级保留文献、已有解析与译文、聊天、笔记和设置；旧档案继续可读，可按需重新生成四部分解读。安装包不包含开发者的个人文库，也不会统一覆盖用户已有档案。

卸载默认保留个人资料；只有在卸载向导明确选择清除并再次确认后，才删除所选资料。安装、升级与资料保留见 [Windows 安装指南](https://github.com/Kumiko-kmk/Copilotix/blob/desktop-v1.2.0/docs/WINDOWS_INSTALLATION_ZH.md)。
