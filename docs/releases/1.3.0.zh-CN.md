# 🎉 Copilotix 1.3.0：流畅文库、阅读编辑与 Zotero 连接

Copilotix 是一款面向论文阅读的 Windows 桌面应用，将 PDF 解析、中文翻译、原文对照与论文问答整合在同一工作区。1.3.0 改善文库切换与双页档案展开，增加阅读器内的段落编辑、删除与排序，接入本机 Zotero，并优化翻译调度、图片显示和资源回收。

## ✨ 本次更新

- 📚 **文库切换更连贯**：跨列点击、搜索、滚轮和方向键共用全库的已保存档案状态，进入档案按钮不再依赖当前封面是否完成渲染。已成熟论文的完整双页封面提前准备并缓存在本地；展开前完成纹理上传，避免动画中途从单页突然补成双页。首次生成、缓存失效或冷文件仍需准备，准备失败可重试，不以半成品开始展开。
- 📐 **档案排版统一**：展开前后的标题、作者、分隔线和四栏正文保持同宽；作者及黑色遮挡限制在栏内。正文仅首行缩进两字，末行自然排列；背景、结论、讨论各点保留 1、2、3 编号，修复短公式异常断行与笔记遮挡。
- ⚡ **后台处理并发与恢复**：最多同时调度 4 篇翻译，Qwen、DeepSeek 翻译各共享最多 16 个请求，档案生成最多 8 篇并行。表格翻译按单元格有限并发并保持顺序，保留限流冷却、重试、取消和已完成单元复用；重启后恢复缺失的档案。实际速度仍受服务商额度、模型和网络影响。
- ✍️ **直接整理阅读内容**：在阅读器内编辑段落、连续删除段落，长按拖动段落或整组图片调整顺序。修改保存在独立的用户编辑层，阅读、翻译、问答和导出共同使用，解析原始产物继续保留；自动文字修复不会覆盖已编辑或删除的段落。
- 🖼️ **图片与问答**：图组默认展示 PDF 原图，可通过右键切换解析子图，选择按论文保存。改善复杂多子图与 Nature 式图说归组；图片可加入论文问答，结合图说及正文提及内容提供上下文。正文参考文献支持悬停查看本文对应条目。
- 🔗 **连接本机 Zotero**：从本机文库选择 PDF 导入，按文件哈希去重并保留来源关联。阅读器可导出总结、标注和笔记；从 Zotero 导入的论文导出为链接回原条目的独立笔记，其他论文可新建条目并附上 PDF。导出前请打开 Zotero，内容写入其当前选中的分类。
- 📄 **解析与显示修复**：利用 PDF 文字层修复部分解析乱码、丢字和伪上下标，导入时预填标题并可跳过机构库封面页。显示设置新增阅读行间距，与主题、字号共用保存和放弃更改流程。
- 🧩 **维护与资源管理**：代码按功能模块整理，并加入自动依赖边界检查。完成的翻译计划、淘汰画布和取消路径资源及时释放，保留硬件加速与阅读预热；实际内存占用随论文和场景变化，不承诺固定降幅。

## 📥 下载与安装

Windows x64 用户下载本 Release 的 **`setup.exe`**，运行安装向导，选择当前用户可写的安装位置，并按需创建桌面图标。完整程序已内嵌，无需下载运行目录。

Release 只提供安装包；下方 **Source code** ZIP／tar.gz 是源代码，不是可直接运行的程序。构建内部继续校验安装包、运行文件和哈希，不单独发布校验清单或运行包 ZIP。

## ⚙️ 首次使用与服务配置

在「设置 → 服务连接」配置 MinerU Token 和所需的翻译／问答服务，测试后保存。使用 Codex 时，先在本机完成账号登录，再选择账号可用模型。安装包不包含 API 密钥、已登录账号或开发者个人文库。

正式导入格式为 PDF；Markdown 是解析、翻译及导出产物。解析会将 PDF 上传至配置的 MinerU 服务；翻译、档案生成和问答会将相关论文文本发送至所选服务，图片问答和图片解读还会发送对应图片。费用、额度和模型可用性以服务商及账号为准，AI 内容应结合原文核对。

Zotero 导入使用本机资料，不需要 Zotero 云端 API Key；导出通过运行中的本机 Zotero 连接器写入。当前连接器不能给已有条目直接追加子笔记，因此关联论文使用可跳回原条目的独立笔记。若条目已建立但 PDF 上传失败，应用会记录部分完成并提示，避免重试时重复创建。

## 🔄 从 1.2.0 及更早版本升级

先等待解析、翻译、档案生成及问答结束，建议通过文库管理创建备份，再从系统托盘退出 Copilotix。仅关闭主窗口可能隐藏到托盘。运行 1.3.0 Setup，沿用现有位置覆盖安装，完成后检查论文、译文、聊天、笔记和设置。

程序安装位置与文库位置相互独立，更改安装位置不会迁移文库。已有解析、译文、档案、聊天和标注继续保留；新封面缓存可以重新生成，不替换原始 PDF。失败或部分完成的旧翻译仍需按需重试，已完成单元会尽量复用；升级本身不会统一重跑论文或付费翻译。

段落排序属于本版用户编辑层扩展，较早版本不一定能读取；回退前先备份，必要时在本版恢复原始顺序。不要用旧版覆盖唯一的文库副本。

## 🗑️ 卸载与个人资料

卸载默认保留文库、任务、设置和凭据；只有在向导明确选择清除，并完成第二次确认后才移除所选资料。外部原始 PDF、外部备份和下载的安装包不会随默认卸载删除。详见 [Windows 安装指南](https://github.com/Kumiko-kmk/Copilotix/blob/desktop-v1.3.0/docs/WINDOWS_INSTALLATION_ZH.md)。

## 📋 验证范围与已知边界

本版本发布流程要求类型、代码规范、模块依赖、全量单元／UI 回归及覆盖率、Electron E2E、安装／升级／卸载、安装包下载及哈希校验通过，之后才公开 Release。对应记录见本 tag 的 [GitHub Actions](https://github.com/Kumiko-kmk/Copilotix/actions/workflows/desktop-windows.yml)。

托管 Windows runner 的软件渲染验证功能和场景确实渲染，不代表真实 GPU 动画帧率；需要本机账号、真实服务或指定论文的可选用例不包含在默认自动化验收中。并发数不等于服务端吞吐保证，本地封面预生成也不代表首次打开任何论文均无等待。
