# 🎉 Copilotix 1.1.0：阅读工作台与论文 AI 问答

Copilotix 是一款面向论文阅读的 Windows 桌面应用，将 PDF 解析、中文翻译、原文对照与论文问答整合在同一工作区。1.1.0 在首个桌面版本的基础上加入可自由分组的阅读工作台和按文献保存的 AI 对话，并改善 PDF 显示、排版与 Markdown 导出。

> ⚠️ **此版本尚未进行受信任的 Windows 代码签名。** Windows 可能显示发布者未知或安全提示；请仅从本 Release 下载，并使用 `SHA256SUMS.txt` 校验文件完整性。未签名不代表已经通过 Windows 发布者身份认证。

## ✨ 本次更新

- 🗂️ **阅读工作台**：PDF、原文 Markdown、中文 Markdown、AI 问答可在同一窗口中自由分组。支持左右或上下拆分、拖动页签、调整分组大小，以及关闭后重新打开视图；布局会在下次使用时恢复。
- ↔️ **拖放与专注阅读**：将页签拖到其他分组可移动或重新排序，拖到内容区边缘可拆分。双击页签或使用 `Ctrl+Shift+M` 最大化当前分组，按 `Esc` 还原。
- 🔗 **段落同步**：原文和译文默认联动，按对应内容块同步阅读位置；PDF 可单独启用同步。AI 回答中的文献引用可定位到阅读视图，便于核对来源。
- 💬 **论文 AI 问答**：支持已启用的 Qwen、DeepSeek 服务及预设模型，可以将阅读选区加入对话。问答模型与翻译模型分别选择，避免切换聊天模型时改变翻译配置。
- 💾 **对话保存在本地**：聊天记录、完整回答、草稿、选区和模型选择随对应文献保存在本地目录，重新打开后恢复；不同文献的对话相互独立。API 密钥不写入聊天文件。
- 📄 **PDF 阅读改善**：清除视图右侧、底部及页间多余留白，采用不占用内容宽高的浮动滚动条。调整栏宽或缩放时保留当前页码与页内阅读位置，减少跳页。
- 📝 **更紧凑的排版**：缩小标题栏、阅读信息栏和页签栏高度，减少正文段落间距，为论文内容留出更多空间。
- 📐 **丰富内容与标准导出**：阅读器保留 HTML 表格与 LaTeX 数学内容；Markdown 和结果 ZIP 导出使用统一的格式处理，并保留相邻图片资源。已有旧版译文不会自动重新解析或翻译。
- 🧹 **界面与体积整理**：移除 JSON 展示和自定义模型入口，保留底层解析产物；旧的自定义模型选择回退到预设模型，历史对话继续保留。整理仅供界面构建使用的依赖，减少安装运行文件中的重复内容。

## 📥 下载与安装

**推荐下载：** `Copilotix-1.1.0-win-x64.zip`（Windows x64）。下载后请完整解压，再运行顶层的 `setup.exe`。安装向导允许选择当前用户可写的安装位置，并可选择是否创建桌面图标。完整程序已内嵌在 Setup 中，无需另行下载运行目录。

也可直接下载独立的 `setup.exe`。本 Release 同时提供 `SHA256SUMS.txt` 和 `release-manifest.json`，用于校验文件与记录发布产物；ZIP 中的 `advanced/` 文件供核验使用，日常安装无需打开。

下载完成后，可在文件所在目录打开 PowerShell，执行 `Get-FileHash .\setup.exe -Algorithm SHA256` 或 `Get-FileHash .\Copilotix-1.1.0-win-x64.zip -Algorithm SHA256`，将结果与本 Release 的 `SHA256SUMS.txt` 对照。

## ⚙️ 首次使用与服务配置

首次启动后，请在「设置 → 服务连接」配置 MinerU Token，以及需要使用的 Qwen 或 DeepSeek 凭据；测试连接后保存设置。PDF 解析、翻译和 AI 问答需要网络及相应服务账号，费用、额度和可用模型以服务商说明为准。本安装包不包含 API 密钥。

当前正式导入格式为 PDF。Markdown 是解析、翻译和导出产物，并非直接导入格式。JSON 不再作为阅读视图显示，但底层解析资料仍保留。

阅读器默认采用「PDF｜原文、中文、问答」布局。右键页签或打开分组的「⋯」菜单，可拆分、移动和关闭视图；关闭的视图可通过「+」重新打开。每个视图只出现一次，移动不会复制内容。分组标题栏中的同步开关控制该视图是否参与段落联动，AI 问答不参与滚动同步。

常用快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4` | 显示 PDF / 原文 / 中文 / AI 问答 |
| `Ctrl+\` | 向右拆分当前视图 |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | 将当前视图移到相邻分组 |
| `Ctrl+W` | 关闭当前视图，保留最后一个可见视图 |
| `Ctrl+Shift+T` | 重新打开最近关闭的视图 |
| `Ctrl+Shift+M` / `Esc` | 最大化当前分组 / 还原 |

## 🔐 本地记录与网络使用

聊天记录保存在对应文献目录的 `chat/` 子目录，关闭阅读器后继续保留；文献删除和聊天清空按应用中的相应操作执行。保存到本地并不表示问答离线运行：开始解析时，PDF 会上传到配置的 MinerU 服务；开始翻译或问答时，相关文献文本、选区与问题会发送到所选服务商。请按文献的使用权限与服务商条款决定是否发送。

凭据由 Windows 系统凭据存储保护，不包含在聊天文件和文库备份中。回答仍应结合原文与引用核对，尤其是公式、数值及结论。

## 🔄 从 1.0.0 升级

升级前请等待解析、翻译及问答任务结束，建议先通过文档库管理创建备份，然后从系统托盘退出 Copilotix；关闭主窗口可能只会隐藏到托盘。运行 1.1.0 的 Setup，沿用现有安装位置完成覆盖安装，再检查任务列表、文献、设置和凭据。

程序安装位置与文库位置相互独立，更改安装位置不会迁移文库。既有文献继续使用原有产物；旧版已生成的平面表格不会因升级自动恢复合并结构，应用也不会自动发起重新解析或付费翻译。

## 🗑️ 卸载与个人资料

卸载默认只移除程序及快捷方式，保留设置、凭据、任务资料与文库。需要清除个人资料时，可在卸载向导勾选移除文库、设置和已保存凭据，并完成第二次确认；此操作不可恢复，请先备份所需内容。

下载的 ZIP、解压目录、外部原始 PDF 和外部备份不会由卸载程序自动删除。更详细的安装、升级和卸载说明见 [Windows 安装指南](https://github.com/Kumiko-kmk/Copilotix/blob/desktop-v1.1.0/docs/WINDOWS_INSTALLATION_ZH.md)。
