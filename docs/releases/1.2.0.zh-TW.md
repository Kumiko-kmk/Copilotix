# 🎉 Copilotix 1.2.0：文庫檔案與閱讀筆記

Copilotix 是一款面向論文閱讀的 Windows 桌面應用，將 PDF 解析、中文翻譯、原文對照與論文問答整合在同一工作區。1.2.0 加入可瀏覽、檢索和展開的文庫檔案，按摘要、背景、結論、討論整理論文，並將高亮、下劃線和筆記帶到檔案展示頁；同時加入 Codex 服務連線與主題外觀設定，改善圖表、翻譯和閱讀體驗。

> ⚠️ **此版本經維護者授權，以未簽章形式釋出。** Windows 可能顯示釋出者未知或安全提示，請從本倉庫 Release 下載。此授權僅適用於 1.2.0，後續版本仍按正式簽章政策執行。

## ✨ 本次更新

- 🗂️ **文庫檔案**：按論文內容分類瀏覽，支援標題檢索、方向鍵及滾輪切換。展開檔案後檢視摘要、背景、結論和討論，點選封面、「開啟閱讀」或再次按 Enter 進入閱讀器；返回文庫時保留所選論文。
- 📄 **四部分解讀**：檔案生成使用完整的已解析論文文字，原文缺少時才使用譯文。背景、結論和討論統一為三點，配有短標題；正文統一字號、首行縮排與點間距，結論可展開原文依據。
- 📝 **標註與筆記**：原文、中文及檔案展示頁支援高亮、下劃線和閱讀筆記，隨文獻儲存在本地。檔案頁選區工具只提供這三項操作；閱讀器仍可將選區加入問答。
- 💬 **Codex 與論文問答**：可連線本機已登入的 Codex，按帳號可用模型選擇翻譯與問答服務；支援逐輪操作與隨問題儲存的閱讀選區，重新開啟後恢復對話和草稿。
- 🖼️ **圖表與封面**：改善多子圖歸組，保留整圖及圖內文字的對應關係；檔案封面展示論文首頁與關鍵圖表，已有圖片解讀用於封面排序。
- 🎨 **主題與排版**：加入三套淺色、三套深色主題及閱讀字號設定，沿用統一的儲存與放棄更改流程。首頁字陣、文庫解密與進入閱讀器的過渡保持一致，減少動態效果設定繼續生效。
- ⚡ **處理與介面整理**：改善翻譯排程、任務恢復和文庫準備狀態，移除舊任務列表、檔案拆解入口及相關資源；閱讀與匯出的表格、公式和圖片繼續保留。

## 📥 下載與安裝

Windows x64 使用者下載本 Release 的 `setup.exe`，執行安裝嚮導即可。完整程式已內嵌，無需另外下載執行目錄。原始碼可透過下方的 **Source code** 下載。

從本版本起，Release 僅提供安裝包及原始碼下載；校驗資訊保留在構建流程內部，不再作為單獨下載檔案釋出。

## ⚙️ 首次使用與服務配置

在「設定 → 服務連線」配置 MinerU Token 和需要使用的翻譯／問答服務，驗證後儲存。使用 Codex 時，先完成本機帳號登入，再在應用中選擇可用模型；安裝包不包含 API 金鑰或已登入帳號。

正式匯入格式仍為 PDF。解析會上傳 PDF 至配置的 MinerU 服務；翻譯和問答向所選服務傳送相關文字。檔案卡在解析後自動生成，使用完整的已解析文字；圖片解讀傳送對應圖片。服務費用、額度與模型可用性以對應帳號為準；檔案中的分析與數值仍應結合原文核對。

## 🔄 從 1.1.0 升級

等待背景任務結束，建議先備份文庫，再從系統匣退出 Copilotix，執行新版本 Setup 完成覆蓋安裝。升級保留文獻、已有解析與譯文、聊天、筆記和設定；舊檔案繼續可讀，可按需重新生成四部分解讀。安裝包不包含開發者的個人文庫，也不會統一覆蓋使用者已有檔案。

解除安裝預設保留個人資料；只有在解除安裝嚮導明確選擇清除並再次確認後，才刪除所選資料。安裝、升級與資料保留見 [Windows 安裝指南](https://github.com/Kumiko-kmk/Copilotix/blob/desktop-v1.2.0/docs/WINDOWS_INSTALLATION_ZH.md)。
