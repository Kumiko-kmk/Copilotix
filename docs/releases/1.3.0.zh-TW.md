# 🎉 Copilotix 1.3.0：流暢文庫、閱讀編輯與 Zotero 連線

Copilotix 是一款面向論文閱讀的 Windows 桌面應用，將 PDF 解析、中文翻譯、原文對照與論文問答整合在同一工作區。1.3.0 改善文庫切換與雙頁檔案展開，增加閱讀器內的段落編輯、刪除與排序，接入本機 Zotero，並最佳化翻譯排程、圖片顯示和資源回收。

> ⚠️ **此版本經維護者授權，以未簽名形式釋出。** Windows 可能顯示釋出者未知或安全提示，請僅從本倉庫 Release 下載。未簽名不表示透過了 Windows 釋出者身份認證；本次授權僅適用於 1.3.0，後續版本繼續執行正式簽名政策。

## ✨ 本次更新

- 📚 **文庫切換更連貫**：跨列點選、搜尋、滾輪和方向鍵共用全庫的已儲存檔案狀態，進入檔案按鈕不再依賴當前封面是否完成渲染。已成熟論文的完整雙頁封面提前準備並快取在本地；展開前完成紋理上傳，避免動畫中途從單頁突然補成雙頁。首次生成、快取失效或冷檔案仍需準備，準備失敗可重試，不以半成品開始展開。
- 📐 **檔案排版統一**：展開前後的標題、作者、分隔線和四欄正文保持同寬；作者及黑色遮擋限制在欄內。正文僅首行縮排兩字，末行自然排列；背景、結論、討論各點保留 1、2、3 編號，修復短公式異常斷行與筆記遮擋。
- ⚡ **背景處理併發與恢復**：最多同時排程 4 篇翻譯，Qwen、DeepSeek 翻譯各共享最多 16 個請求，檔案生成最多 8 篇並行。表格翻譯按單元格有限併發並保持順序，保留限流冷卻、重試、取消和已完成單元複用；重啟後恢復缺失的檔案。實際速度仍受服務商額度、模型和網路影響。
- ✍️ **直接整理閱讀內容**：在閱讀器內編輯段落、連續刪除段落，長按拖動段落或整組圖片調整順序。修改儲存在獨立的使用者編輯層，閱讀、翻譯、問答和匯出共同使用，解析原始產物繼續保留；自動文字修復不會覆蓋已編輯或刪除的段落。
- 🖼️ **圖片與問答**：圖組預設展示 PDF 原圖，可透過右鍵切換解析子圖，選擇按論文儲存。改善複雜多子圖與 Nature 式圖說歸組；圖片可加入論文問答，結合圖說及正文提及內容提供上下文。正文參考文獻支援懸停檢視本文對應條目。
- 🔗 **連線本機 Zotero**：從本機文庫選擇 PDF 匯入，按檔案雜湊去重並保留來源關聯。閱讀器可匯出總結、標註和筆記；從 Zotero 匯入的論文匯出為連結回原條目的獨立筆記，其他論文可新建條目並附上 PDF。匯出前請開啟 Zotero，內容寫入其當前選中的分類。
- 📄 **解析與顯示修復**：利用 PDF 文字層修復部分解析亂碼、丟字和偽上下標，匯入時預填標題並可跳過機構庫封面頁。顯示設定新增閱讀行間距，與主題、字號共用儲存和放棄更改流程。
- 🧩 **維護與資源管理**：程式碼按功能模組整理，並加入自動依賴邊界檢查。完成的翻譯計劃、淘汰畫布和取消路徑資源及時釋放，保留硬體加速與閱讀預熱；實際記憶體佔用隨論文和場景變化，不承諾固定降幅。

## 📥 下載與安裝

Windows x64 使用者下載本 Release 的 **`setup.exe`**，執行安裝嚮導，選擇當前使用者可寫的安裝位置，並按需建立桌面圖示。完整程式已內嵌，無需下載執行目錄。

Release 只提供安裝包；下方 **Source code** ZIP／tar.gz 是原始碼，不是可直接執行的程式。構建內部繼續校驗安裝包、執行檔案和雜湊，不單獨釋出校驗清單或執行包 ZIP。

## ⚙️ 首次使用與服務配置

在「設定 → 服務連線」配置 MinerU Token 和所需的翻譯／問答服務，測試後儲存。使用 Codex 時，先在本機完成帳號登入，再選擇帳號可用模型。安裝包不包含 API 金鑰、已登入帳號或開發者個人文庫。

正式匯入格式為 PDF；Markdown 是解析、翻譯及匯出產物。解析會將 PDF 上傳至配置的 MinerU 服務；翻譯、檔案生成和問答會將相關論文文字傳送至所選服務，圖片問答和圖片解讀還會傳送對應圖片。費用、額度和模型可用性以服務商及帳號為準，AI 內容應結合原文核對。

Zotero 匯入使用本機資料，不需要 Zotero 雲端 API Key；匯出透過執行中的本機 Zotero 聯結器寫入。當前聯結器不能給已有條目直接追加子筆記，因此關聯論文使用可跳回原條目的獨立筆記。若條目已建立但 PDF 上傳失敗，應用會記錄部分完成並提示，避免重試時重複建立。

## 🔄 從 1.2.0 及更早版本升級

先等待解析、翻譯、檔案生成及問答結束，建議透過文庫管理建立備份，再從系統匣退出 Copilotix。僅關閉主視窗可能隱藏到托盤。執行 1.3.0 Setup，沿用現有位置覆蓋安裝，完成後檢查論文、譯文、聊天、筆記和設定。

程式安裝位置與文庫位置相互獨立，更改安裝位置不會遷移文庫。已有解析、譯文、檔案、聊天和標註繼續保留；新封面快取可以重新生成，不替換原始 PDF。失敗或部分完成的舊翻譯仍需按需重試，已完成單元會盡量複用；升級本身不會統一重跑論文或付費翻譯。

段落排序屬於本版使用者編輯層擴充套件，較早版本不一定能讀取；回退前先備份，必要時在本版恢復原始順序。不要用舊版覆蓋唯一的文庫副本。

## 🗑️ 解除安裝與個人資料

解除安裝預設保留文庫、任務、設定和憑據；只有在嚮導明確選擇清除，並完成第二次確認後才移除所選資料。外部原始 PDF、外部備份和下載的安裝包不會隨預設解除安裝刪除。詳見 [Windows 安裝指南](https://github.com/Kumiko-kmk/Copilotix/blob/desktop-v1.3.0/docs/WINDOWS_INSTALLATION_ZH.md)。
