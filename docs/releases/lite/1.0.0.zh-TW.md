# 🎉 Copilotix Lite 1.0：專注閱讀的獨立桌面版

Copilotix Lite 的首個版本，把 PDF、原文、中文和論文問答放進簡潔介面；與完整版分別安裝和儲存資料。

> 本版本經維護者授權，以未簽名形式釋出。Windows 可能顯示“未知釋出者”。

## ✨ 本次更新

- 列表側欄支援中英文標題模糊搜尋、置頂、分類、重新命名和刪除。
- 支援雙論文分屏與獨立閱讀視窗，保留四檢視工作臺。
- 正文雙擊編輯；移除整段邊框及上移／下移入口，歷史編輯繼續讀取。
- 參考文獻懸停卡片可移入並停留，點選複製編號後的條目內容。
- 服務、儲存、外觀三個設定頁面，Codex 使用本機登入與自動發現。
- 儲存統計只在開啟相應頁面時讀取，不自動輪詢 Codex。
- 不包含完整版的首頁字元特效、視覺化文庫及自動檔案生成；載入狀態不播放翻轉動畫。
- 此發行版本原先使用簡體中文介面，可在不同系統語言的 Windows 上正常啟動。

## 📥 下載與安裝

Windows x64 使用者下載本 Release 的 `setup.exe`，完整執行檔案已內嵌。原始碼 ZIP／tar.gz 由 GitHub 提供，無需為執行程式下載。

## ⚙️ 首次使用與服務配置

在「設定 → 服務」填寫 MinerU Token 和需要使用的模型 API Key，驗證後儲存。Qwen／DeepSeek 的翻譯開關控制對應來源是否參與翻譯；Codex 需要本機已安裝並登入。程式不提供憑據，不包含模型服務費用。

## 🔄 資料與完整版並存

Lite 使用獨立的安裝身份、`Copilotix-Lite` 應用資料及 `Copilotix Lite` 文件目錄，可與完整版同時安裝和執行。文獻可透過匯出／匯入轉移，API Key 分別配置。後續覆蓋升級保留資料。

## 🗑️ 解除安裝與個人資料

普通解除安裝保留文庫、設定及憑據。需要移除個人資料時，在解除安裝嚮導選擇清除，並完成第二次確認。外部原始 PDF、外部備份和下載的安裝包繼續保留。

## 📋 釋出驗證

釋出流程檢查型別、程式碼規範、模組依賴、單元／UI 迴歸與覆蓋率、Lite Electron 閱讀流程、隔離安裝／升級／解除安裝、已安裝程式的首頁與設定介面，以及安裝包回下載 SHA-256。記錄見本 tag 的 [GitHub Actions](https://github.com/Kumiko-kmk/Copilotix/actions/workflows/desktop-lite-windows.yml)。

支援 Windows x64，介面固定為簡體中文。解析使用 MinerU；翻譯和問答使用已配置的 Qwen、DeepSeek 或本機 Codex。真實服務的費用、額度及模型可用性由對應帳號決定。
