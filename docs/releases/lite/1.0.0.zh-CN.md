# 🎉 Copilotix Lite 1.0：专注阅读的独立桌面版

Copilotix Lite 的首个版本，把 PDF、原文、中文和论文问答放进简洁界面；与完整版分别安装和保存资料。

> 本版本经维护者授权，以未签名形式发布。Windows 可能显示“未知发布者”。

## ✨ 本次更新

- 列表侧栏支持中英文标题模糊搜索、置顶、分类、重命名和删除。
- 支持双论文分屏与独立阅读窗口，保留四视图工作台。
- 正文双击编辑；移除整段边框及上移／下移入口，历史编辑继续读取。
- 参考文献悬停卡片可移入并停留，点击复制编号后的条目内容。
- 服务、存储、外观三个设置页面，Codex 使用本机登录与自动发现。
- 存储统计只在打开相应页面时读取，不自动轮询 Codex。
- 不包含完整版的首页字符特效、可视化文库及自动档案生成；加载状态不播放翻转动画。
- 固定简体中文界面，可在不同系统语言的 Windows 上正常启动。

## 📥 下载与安装

Windows x64 用户下载本 Release 的 `setup.exe`，完整运行文件已内嵌。源代码 ZIP／tar.gz 由 GitHub 提供，无需为运行程序下载。

## ⚙️ 首次使用与服务配置

在「设置 → 服务」填写 MinerU Token 和需要使用的模型 API Key，验证后保存。Qwen／DeepSeek 的翻译开关控制对应来源是否参与翻译；Codex 需要本机已安装并登录。程序不提供凭据，不包含模型服务费用。

## 🔄 数据与完整版并存

Lite 使用独立的安装身份、`Copilotix-Lite` 应用数据及 `Copilotix Lite` 文档目录，可与完整版同时安装和运行。文献可通过导出／导入转移，API Key 分别配置。后续覆盖升级保留资料。

## 🗑️ 卸载与个人资料

普通卸载保留文库、设置及凭据。需要移除个人资料时，在卸载向导选择清除，并完成第二次确认。外部原始 PDF、外部备份和下载的安装包继续保留。

## 📋 发布验证

发布流程检查类型、代码规范、模块依赖、单元／UI 回归与覆盖率、Lite Electron 阅读流程、隔离安装／升级／卸载、已安装程序的首页与设置界面，以及安装包回下载 SHA-256。记录见本 tag 的 [GitHub Actions](https://github.com/Kumiko-kmk/Copilotix/actions/workflows/desktop-lite-windows.yml)。

支持 Windows x64，界面固定为简体中文。解析使用 MinerU；翻译和问答使用已配置的 Qwen、DeepSeek 或本机 Codex。真实服务的费用、额度及模型可用性由对应账号决定。
