# Copilotix Lite 1.0：专注阅读的独立桌面版

Copilotix Lite 的首个版本，把 PDF、原文、中文和论文问答放进简洁界面；与完整版分别安装和保存资料。

## 本版功能

- 列表侧栏支持中英文标题模糊搜索、置顶、分类、重命名和删除。
- 支持双论文分屏与独立阅读窗口，保留四视图工作台。
- 正文双击编辑；移除整段边框及上移／下移入口，历史编辑继续读取。
- 参考文献悬停卡片可移入并停留，点击复制编号后的条目内容。
- 服务、存储、外观三个设置页面，Codex 使用本机登录与自动发现。
- 存储统计只在打开相应页面时读取，不自动轮询 Codex。
- 不包含完整版的首页字符特效、可视化文库及自动档案生成；加载状态不播放翻转动画。

## 下载与安装

Windows x64 用户下载本 Release 的 `setup.exe`，完整运行文件已内嵌。源代码 ZIP／tar.gz 由 GitHub 提供，无需为运行程序下载。

此版本的最终签章状态将在发布前确认；本文件存在不代表安装包已经公开。

## 配置服务

在「设置 → 服务」填写 MinerU Token 和需要使用的模型 API Key，验证后保存。Qwen／DeepSeek 的翻译开关控制对应来源是否参与翻译；Codex 需要本机已安装并登录。程序不提供凭据，不包含模型服务费用。

## 数据与完整版并存

Lite 使用独立的安装身份、`Copilotix-Lite` 应用数据及 `Copilotix Lite` 文档目录，不自动读取或覆盖完整版。文献可通过导出／导入转移，API Key 需重新配置。覆盖升级及普通卸载保留资料；清除数据需要明确确认。

## 边界

继续采用 Electron／React／SQLite。未宣称固定的内存或速度提升。解析及模型功能需要相应服务可用；本地回归不代替真实账号、付费模型与个人文库验收。
