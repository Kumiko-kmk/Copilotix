# 🎉 Copilotix 1.1.0：閱讀工作臺與論文 AI 問答

Copilotix 是一款面向論文閱讀的 Windows 桌面應用，將 PDF 解析、中文翻譯、原文對照與論文問答整合在同一工作區。1.1.0 在首個桌面版本的基礎上加入可自由分組的閱讀工作臺和按文獻儲存的 AI 對話，並改善 PDF 顯示、排版與 Markdown 匯出。

> ⚠️ **此版本尚未進行受信任的 Windows 程式碼簽名。** Windows 可能顯示釋出者未知或安全提示；請僅從本 Release 下載，並使用 `SHA256SUMS.txt` 校驗檔案完整性。未簽名不代表已經透過 Windows 釋出者身份認證。

## ✨ 本次更新

- 🗂️ **閱讀工作臺**：PDF、原文 Markdown、中文 Markdown、AI 問答可在同一視窗中自由分組。支援左右或上下拆分、拖動頁籤、調整分組大小，以及關閉後重新開啟檢視；版面配置會在下次使用時恢復。
- ↔️ **拖放與專注閱讀**：將頁籤拖到其他分組可移動或重新排序，拖到內容區邊緣可拆分。雙擊頁籤或使用 `Ctrl+Shift+M` 最大化當前分組，按 `Esc` 還原。
- 🔗 **段落同步**：原文和譯文預設聯動，按對應內容塊同步閱讀位置；PDF 可單獨啟用同步。AI 回答中的文獻引用可定位到閱讀檢視，便於核對來源。
- 💬 **論文 AI 問答**：支援已啟用的 Qwen、DeepSeek 服務及預設模型，可以將閱讀選區加入對話。問答模型與翻譯模型分別選擇，避免切換聊天模型時改變翻譯配置。
- 💾 **對話儲存在本地**：聊天記錄、完整回答、草稿、選區和模型選擇隨對應文獻儲存在本地目錄，重新開啟後恢復；不同文獻的對話相互獨立。API 金鑰不寫入聊天檔案。
- 📄 **PDF 閱讀改善**：清除檢視右側、底部及頁間多餘留白，採用不佔用內容寬高的浮動捲軸。調整欄寬或縮放時保留當前頁碼與頁內閱讀位置，減少跳頁。
- 📝 **更緊湊的排版**：縮小標題欄、閱讀資訊欄和頁籤欄高度，減少正文段落間距，為論文內容留出更多空間。
- 📐 **豐富內容與標準匯出**：閱讀器保留 HTML 表格與 LaTeX 數學內容；Markdown 和結果 ZIP 匯出使用統一的格式處理，並保留相鄰圖片資源。已有舊版譯文不會自動重新解析或翻譯。
- 🧹 **介面與體積整理**：移除 JSON 展示和自定義模型入口，保留底層解析產物；舊的自定義模型選擇回退到預設模型，歷史對話繼續保留。整理僅供介面構建使用的依賴，減少安裝執行檔案中的重複內容。

## 📥 下載與安裝

**推薦下載：** `Copilotix-1.1.0-win-x64.zip`（Windows x64）。下載後請完整解壓，再執行頂層的 `setup.exe`。安裝嚮導允許選擇當前使用者可寫的安裝位置，並可選擇是否建立桌面圖示。完整程式已內嵌在 Setup 中，無需另行下載執行目錄。

也可直接下載獨立的 `setup.exe`。本 Release 同時提供 `SHA256SUMS.txt` 和 `release-manifest.json`，用於校驗檔案與記錄釋出產物；ZIP 中的 `advanced/` 檔案供核驗使用，日常安裝無需開啟。

下載完成後，可在檔案所在目錄開啟 PowerShell，執行 `Get-FileHash .\setup.exe -Algorithm SHA256` 或 `Get-FileHash .\Copilotix-1.1.0-win-x64.zip -Algorithm SHA256`，將結果與本 Release 的 `SHA256SUMS.txt` 對照。

## ⚙️ 首次使用與服務配置

首次啟動後，請在「設定 → 服務連線」配置 MinerU Token，以及需要使用的 Qwen 或 DeepSeek 憑據；測試連線後儲存設定。PDF 解析、翻譯和 AI 問答需要網路及相應服務帳號，費用、額度和可用模型以服務商說明為準。本安裝包不包含 API 金鑰。

當前正式匯入格式為 PDF。Markdown 是解析、翻譯和匯出產物，並非直接匯入格式。JSON 不再作為閱讀檢視顯示，但底層解析資料仍保留。

閱讀器預設採用「PDF｜原文、中文、問答」版面配置。右鍵頁籤或開啟分組的「⋯」選單，可拆分、移動和關閉檢視；關閉的檢視可透過「+」重新開啟。每個檢視只出現一次，移動不會複製內容。分組標題欄中的同步開關控制該檢視是否參與段落聯動，AI 問答不參與滾動同步。

常用快捷鍵：

| 快捷鍵 | 操作 |
| --- | --- |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4` | 顯示 PDF / 原文 / 中文 / AI 問答 |
| `Ctrl+\` | 向右拆分當前檢視 |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | 將當前檢視移到相鄰分組 |
| `Ctrl+W` | 關閉當前檢視，保留最後一個可見檢視 |
| `Ctrl+Shift+T` | 重新開啟最近關閉的檢視 |
| `Ctrl+Shift+M` / `Esc` | 最大化當前分組 / 還原 |

## 🔐 本地記錄與網路使用

聊天記錄儲存在對應文獻目錄的 `chat/` 子目錄，關閉閱讀器後繼續保留；文獻刪除和聊天清空按應用中的相應操作執行。儲存到本地並不表示問答離線執行：開始解析時，PDF 會上傳到配置的 MinerU 服務；開始翻譯或問答時，相關文獻文字、選區與問題會傳送到所選服務商。請按文獻的使用許可權與服務商條款決定是否傳送。

憑據由 Windows 系統憑據儲存保護，不包含在聊天檔案和文庫備份中。回答仍應結合原文與引用核對，尤其是公式、數值及結論。

## 🔄 從 1.0.0 升級

升級前請等待解析、翻譯及問答任務結束，建議先透過文件庫管理建立備份，然後從系統匣退出 Copilotix；關閉主視窗可能只會隱藏到托盤。執行 1.1.0 的 Setup，沿用現有安裝位置完成覆蓋安裝，再檢查任務列表、文獻、設定和憑據。

程式安裝位置與文庫位置相互獨立，更改安裝位置不會遷移文庫。既有文獻繼續使用原有產物；舊版已生成的平面表格不會因升級自動恢復合併結構，應用也不會自動發起重新解析或付費翻譯。

## 🗑️ 解除安裝與個人資料

解除安裝預設只移除程式及捷徑，保留設定、憑據、任務資料與文庫。需要清除個人資料時，可在解除安裝嚮導勾選移除文庫、設定和已儲存憑據，並完成第二次確認；此操作不可恢復，請先備份所需內容。

下載的 ZIP、解壓目錄、外部原始 PDF 和外部備份不會由解除安裝程式自動刪除。更詳細的安裝、升級和解除安裝說明見 [Windows 安裝指南](https://github.com/Kumiko-kmk/Copilotix/blob/desktop-v1.1.0/docs/WINDOWS_INSTALLATION_ZH.md)。
